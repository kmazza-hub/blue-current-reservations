# BLUE CURRENT V47.15.0 — OUTCOME MEASUREMENT

## Scope

V47.11–V47.15 closes the next loop in Hospitality Performance Command.

V47.10 tracked whether a manager owned and completed an action.

V47.15 now asks the more important question:

`Did the operating problem actually improve?`

Completion alone is no longer treated as success.

## V47.11 — Start / Completion State Capture

Action workspaces now distinguish:
- created time
- started time
- completed time

When an action reaches `in_progress`, Blue Current records its execution start.

When an action reaches `completed`, Blue Current captures a fresh live Hospitality Performance snapshot for the original opportunity.

## V47.12 — Baseline vs Live Exposure

Each action already stores the expected-impact baseline from the opportunity at acceptance.

At completion Blue Current compares:

- original opportunity exposure
- remaining live opportunity exposure

If the original opportunity disappears from the live queue, the exposure is treated as resolved.

If it remains, Blue Current measures how much exposure is still present.

## V47.13 — Realized Impact

Outcome measurement now calculates:

- improvement percentage
- realized impact dollars
- expected impact dollars
- realization rate
- time-to-resolution
- whether the target was met
- outcome status

Outcome states:

- `improved`
- `partial`
- `not-improved`

A completed action with no operating improvement is recorded as:

`not-improved`

It is not silently credited as a success.

## V47.14 — Outcome Remeasurement

Adds:

`POST /api/hospitality-actions/:workspaceId/remeasure`

A completed action can be measured again later.

This is important because some restaurant interventions do not show their full result immediately.

Remeasurement updates the current operating evidence and outcome result without changing the historical action timeline.

## V47.15 — Outcome Measurement UI

The Action Workspace now shows:
- realized impact
- realization rate
- action-level outcome status
- improvement percentage
- realized vs expected impact
- time-to-resolution
- Remeasure Outcome control

A new **Outcome Measurement** surface summarizes:
- measured outcomes
- improved actions
- actions that did not improve
- realized impact dollars
- realization rate
- average resolution time
- per-action outcome evidence

## Measurement policy

`completionDoesNotImplySuccess: true`

The current V47.15 model uses the original opportunity's modeled dollar exposure as the baseline and the live remaining opportunity exposure as the completion-state comparison.

This is intentionally conservative.

If the same opportunity remains at the same modeled exposure after a manager marks an action complete, Blue Current records:

- 0% improvement
- $0 realized impact
- `not-improved`
