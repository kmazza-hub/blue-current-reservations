# V77.50.1 — Command Auth + Diagnostics Dock Hotfix

This hotfix addresses two issues visible in the V77 operator screen.

## Diagnostics badge clearance
The startup diagnostics badge no longer overlays the Quick Jobs / operator bar.
- compact 42px dock
- top-right placement
- full diagnostic panel remains available on click
- mobile placement remains clear of bottom operating controls

## Startup diagnostic false warning
The diagnostics module was still comparing the Cloud API client against a legacy V38.5.4 build string, which could produce a false `3/4 core checks passed` state.
V77.50.1 checks that a valid API client/version is present instead of requiring an obsolete exact version match.

## Command authentication resilience
Command calls now:
- stop polling protected endpoints while the auth overlay is open
- detect HTTP 401
- trigger the existing Blue Current session-expired flow
- suppress repeated unauthorized Command polling until sign-in
- resume after sign-in

## Tunnel/upstream resilience
Command HTTP 502/503/504 responses now trigger a short transport backoff rather than immediately retrying every Command surface.

This does not hide a real Cloudflare tunnel outage. `/api/events` can still show a 502 while the tunnel or local server is disconnected; that condition must be corrected at the tunnel/server layer.
