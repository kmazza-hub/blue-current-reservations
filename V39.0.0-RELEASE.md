# Blue Current V39.0.0 — Runtime Stabilization

This release establishes the V39 stabilization baseline after the Operations pack recovery.

## Changes
- Coalesces shared-state rendering to one animation-frame update.
- Removes normal console flooding from state synchronization.
- Adds optional state diagnostics through `?debugState=1`.
- Restricts Shift Intelligence recalculation to material operating keys.
- Adds re-entry and unchanged-input protection to Shift Intelligence.
- Preserves the six-script minimal Operations pack.
- Updates startup and asset cache identifiers to V39.0.0.
