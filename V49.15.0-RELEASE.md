# BLUE CURRENT V49.15.0 — LOCATION DEPLOYMENT PACKAGE

V49.11–V49.15 turns technical go-live authorization into a concrete, restaurant-specific deployment package while preserving a hard separation between preparation and production execution.

## Location deployment manifest

Each prepared package contains:

- location / rollout wave
- technical readiness at package time
- human go-live authorization reference
- go-live approver
- deployment owner
- rollback owner
- launch window
- configuration requirements
- user/access requirements
- module enablement matrix
- connector/integration requirements
- remaining blockers and warnings
- launch runbook
- rollback runbook
- deployment note

## Module enablement matrix

The deployment package explicitly records readiness for:

- Floor
- Reservations
- Kitchen
- Workforce

Blue Current does not silently enable a module because a package was created.

## Launch and rollback runbooks

Every package carries a launch sequence that requires:

1. re-confirmed human go-live authorization
2. current technical-readiness recheck
3. deployment and rollback owners present
4. configuration and access verification
5. module/integration verification
6. a separate explicit deployment execution workflow
7. post-cutover health and data-integrity checks
8. stabilization monitoring

Rollback includes:

- stop further cutover actions
- restore the last certified application/configuration checkpoint
- disable newly introduced connector traffic where applicable
- verify reservation/floor/kitchen/workforce/auth integrity
- record incident and recovery evidence before resuming launch

## Critical separation

A prepared package is stored as:

- `status: READY_FOR_DEPLOYMENT_EXECUTION`
- `deploymentExecutionState: NOT_STARTED`
- `productionCutoverState: NOT_PERFORMED`

Policy:

- `goLiveAuthorizationRequired: true`
- `adminPackagePreparationRequired: true`
- `packagePreparationDoesNotDeploy: true`
- `deploymentExecutionSeparate: true`
- `automaticProvisioning: false`
- `automaticDeployment: false`
- `automaticCutover: false`

## API

GET `/api/location-deployment-package`

GET `/api/location-deployment-package/locations/:locationId/packet`

POST `/api/location-deployment-package/locations/:locationId/prepare`

Package preparation is admin-only and respects authenticated location scope.
