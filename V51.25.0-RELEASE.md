# BLUE CURRENT V51.25.0 — ROLE & PERMISSION CERTIFICATION

V51.21–V51.25 certifies Blue Current's role, permission, membership, location-scope, and API authorization model before restaurant pilot use.

## Permission hardening discovered during certification

The V51.25 audit found a real authorization inconsistency:

- the API already contained multiple `authService.can(auth,"admin")` guards
- the existing AuthService did not grant the `admin` permission to either `owner` or `administrator`

That made admin-only pilot controls unreachable through the intended owner/administrator roles.

V51.25 fixes the permission source of truth before certification.

## UI versus authorization

Blue Current's role-experience UI is treated as presentation, not security.

The API remains the authorization boundary.

The certification exposes the intended UI profiles:

- executive
- manager
- technical

but hiding a UI section never substitutes for server-side authorization.
