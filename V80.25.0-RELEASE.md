# V80.25.0 — Pilot Runtime Guardrails & Service-Night Safety

Adds the live-service safety envelope around the V80 pilot cutover.

Runtime states:
- NORMAL
- WATCH
- DEGRADED
- OPERATOR_HOLD
- EMERGENCY_LOCAL

Critical incidents force local operation and roll back provider authority.
Provider continuity loss blocks external writes.
Operators can explicitly hold external authority during service.
Autonomous production changes and destructive automation remain disabled.
Local restaurant operation remains available throughout provider failure.
