# V100.2.52 — Service Milestones & Next Action

This wave turns the first Service surface into a usable operating flow while preserving the stabilized Host Stand.

- Every active table has one current service state and one obvious next action.
- Service states advance: **Just seated → Greeted → Ordering → Dining → Check down → Complete**.
- The action button changes with the state instead of showing a permanent premature `Complete service` button.
- Tables that remain ungreeted for 3+ minutes receive a restrained attention treatment and contribute to a **Needs greeting** count.
- The row keeps guest, party, table, and seated elapsed time visible without adding a dense dashboard.
- Service state changes persist in the existing V100.2.50 active-service store.
- Completing service removes the table through the same authoritative handoff API.
- Floor geometry/readability, Reservations, Waitlist, Guests, and Guest Recognition/Memory are unchanged.

Design rule: **one table, one state, one obvious next action.**
