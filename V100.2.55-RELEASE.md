# V100.2.55 — Service First Priority

Makes the Service workspace answer one question immediately: **what needs me first?**

- Adds a compact First priority strip above Active tables.
- If a table is overdue, the strip names the guest/table and the exact next action.
- If Service is on pace, the strip says so and points to the oldest active table without manufacturing urgency.
- Retains stage-aware pacing and overdue ordering from V100.2.54.
- Includes a compatibility repair for the V100.2.54 apply guard, so a verified V100.2.53 floor baseline can move forward safely even if V100.2.54 did not apply.
- Does not replace or redesign the floor renderer.

Architecture: guarded, in-place Service-only patch. Floor room isolation and cell readability are explicitly protected.
