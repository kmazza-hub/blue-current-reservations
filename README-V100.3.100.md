# Blue Current V100.3.100 — Universal Current-System Certification

V100.3.100 establishes one authoritative certification command for the supported current Blue Current system.

## Certification boundary

- Validates every JavaScript file, client script, and HTML identity.
- Preserves the V100.3.97 iPhone dismissal and responsive contracts.
- Preserves the V100.3.98 holiday reservation book.
- Preserves the V100.3.99 reservation-toolbar readability fix.
- Runs full reservation, waitlist, floor, service, kitchen, staffing, scheduling, time-clock, persistence, restart, and rush/collision lifecycle tests.
- Measures every declared frontline API against a 1.5-second local response target.
- Verifies every local client asset exists.
- Classifies exact historical release snapshots as preserved non-blocking evidence rather than current behavior contracts.

Legacy certification, expansion, and readiness dashboards remain available as evidence surfaces but do not override the current frontline operating contract.

## Commands

```powershell
npm run certify:universal
```

The existing pilot command runs the same universal current-system certification:

```powershell
npm run certify:pilot
```

The mock restaurant day can also be run independently:

```powershell
npm run test:mock-day
```

All runtime tests use disposable database copies. Certification does not deploy, alter the live database, authorize a pilot, or replace physical iPhone/iPad sign-off.
