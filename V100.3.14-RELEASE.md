# V100.3.14 — Staff Data Credibility

Forward-only staffing truth refinement from V100.3.13.

## Certified improvements

- Calculates “Today” labor from only the portion of a punch overlapping the current local calendar day.
- Keeps old open punches visible while marking them as manager-review exceptions.
- Prevents stale punches from inflating labor cost or overtime exposure across multiple days.
- Prioritizes punch-review exceptions in the focused Staff workspace.

## Preserved

- Recorded Time Clock API remains the sole source for the focused Staff view.
- Clock-in, clock-out, break, and correction actions remain unchanged.
- Stored timecard records are not silently rewritten by snapshot reads.
- Focused workspace, host, floor, seating, and guest lifecycle behavior remains intact.
