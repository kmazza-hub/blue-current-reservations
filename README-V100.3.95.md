# Blue Current V100.3.95 — Installed App Identity

This presentation-only release gives Blue Current a polished installed-app identity on Windows, iPhone, and iPad.

- The browser and desktop shortcut title is shortened to `Blue Current`, preventing the wrapped and truncated label seen on Windows.
- A refined full-bleed ocean-current icon adds a restrained golden sunrise accent while preserving the established wave mark.
- Dedicated favicon, Apple touch, standard PWA, and maskable assets cover the device sizes used by current browsers.
- The manifest retains standalone launch behavior and asks supported desktop browsers to reuse the existing app window.
- No service worker or unsupported offline claim is introduced.
- No restaurant data, readiness evidence, authentication, service workflow, or launch-control behavior is changed.
