# V82.25.0 — Controlled Expansion Planning & Location Readiness

Adds independent readiness certification for every candidate expansion location.

A prior executive EXPAND decision from the source pilot is required, but it does
not make another restaurant ready automatically.

Location readiness covers:
- launch/training/support ownership
- operating configuration
- staff and manager training
- local fallback
- emergency contacts
- support coverage
- opening hours
- floor/menu configuration
- provider location mapping / connection progress

The resulting approval is only ROLLOUT_PREP_APPROVED.
It does not authorize production activation or provider authority.
