# V86.0.0 — Integration Readiness & Connector Data Trust

Phase B begins with a provider-neutral integration certification layer.

Every pilot connector must prove identity, connectivity, schema contract, incremental
sync, reconciliation, freshness, failure isolation, and auditability. Blue Current
surfaces stale or unreconciled data rather than treating it as trustworthy.

Toast receives an explicit integration profile, but V86 does not falsely claim vendor
certification. Production certification requires real provider credentials/data and
successful reconciliation. Connector write-back remains disabled by default.
