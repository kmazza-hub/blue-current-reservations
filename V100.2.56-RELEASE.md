# V100.2.56 — Service Exception / Recovery Intelligence

Turns Service First Priority into restrained recovery intelligence.

- Keeps V100.2.55 priority ordering and stage-aware pacing intact.
- Adds a distinct recovery threshold at 1.5× the expected stage pace, preventing every small delay from becoming an "exception."
- Escalates the First Priority strip to **Recovery needed** only when a table has meaningfully fallen off pace.
- Explains what Blue Current actually knows from lifecycle state and elapsed stage time.
- Gives one concrete recovery action for the current stage.
- Does not infer or invent whether the server, kitchen, guest, payment process, or another cause created the delay.
- Does not add a manager dashboard, queue, modal, or second workflow.
- Protects the V100.2.47 Floor section byte-for-byte during apply.

This wave intentionally does **not** revive the older V92-era exception queue or service-recovery playbook surfaces. Those are broader management systems and would violate the current operator-first Service objective.
