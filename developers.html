Technical diligence

Clear answers before implementation begins.

Is a public self-service API available today?

This page describes Blue Current's API-first architecture and integration model. Specific endpoints, environments, credentials, and production readiness are confirmed during technical discovery; no unsupported public-API claim is made.

How are breaking changes handled?

Contracts are designed around explicit versioning, compatibility review, deprecation planning, and controlled promotion between environments.

How are duplicate events and retries managed?

Integration designs use source identifiers, idempotency keys, workflow state, reconciliation, and observable retry behavior appropriate to the connected system.

Can Blue Current support webhooks and outbound actions?

Event delivery and outbound actions are scoped per workflow, including destination authentication, retries, signatures, permissions, approval requirements, and failure ownership.
