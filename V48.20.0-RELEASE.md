# BLUE CURRENT V48.20.0 — PILOT DECISION LEDGER & EXECUTIVE SIGN-OFF

## V48.16–V48.20
This wave separates Blue Current's recommendation from the actual human commercial decision.

### Added
- persistent pilot decision ledger
- admin-only executive sign-off API
- human decision: CONTINUE / INTERVENE / EXPAND / PAUSE / CLOSE
- named approver and signing actor
- conditions / rationale
- follow-up obligation
- explicit rollout location scope
- evidence snapshot at signing time
- system recommendation captured alongside the human decision
- override detection
- complete decision history
- audit + realtime event

### Expansion guards
- EXPAND requires explicit rollout locations.
- Unauthorized rollout locations are rejected.
- If leadership expands against a non-EXPAND Blue Current recommendation, documented executive conditions are mandatory.
- Blue Current never approves or executes expansion automatically.

Policy:
- humanSignatureRequired: true
- automaticApproval: false
- automaticExpansion: false
- systemRecommendationIsNonBinding: true

### Permission boundary
Signing is deliberately restricted to authenticated users with `admin` permission.
The current demo account used for integration testing is not an admin; authenticated ledger reads pass and its attempted sign-off correctly returns HTTP 403. The focused service test validates the full successful signing lifecycle independently.
