# Blue Current V100.3.5 — iPad Deterministic Viewport + Full-Screen Floor

This wave combines the two physical-iPad findings from V100.3.4 into one restrained operator upgrade.

## 1. Deterministic Quick Job destinations
- Find guest locks to the actual guest-search panel and focuses the search field.
- Service / Run floor locks to the live digital-twin floor workspace rather than the page intro.
- Kitchen / Pressure locks to the Kitchen Throughput Coach header.
- Staff / Coverage locks to the live-truth staffing surface when it is present.
- Viewport locking re-applies while Safari visual-viewport/layout changes settle, preventing the small post-navigation drift observed on the physical iPad.

## 2. Full-screen Floor workspace
- Adds a `Full screen floor` control to the Host floor toolbar.
- `Floor` Quick Job enters full-screen floor mode automatically.
- Choosing `Seat` enters the same focused floor mode automatically.
- Full-screen mode uses the full software viewport, keeps section controls visible, enlarges table targets, hides the Quick Jobs dock, and provides clear Back / Exit controls.
- Seating lifecycle semantics are unchanged.

## Scope guard
No server, authentication, API, reservation, seating-state, Kitchen truth, Service truth, or staffing-truth semantics were changed.
