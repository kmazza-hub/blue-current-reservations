## Test evidence model

Every scenario result requires human-recorded evidence.

Failure/reconnect scenarios require additional human-recorded recovery evidence before PASS is accepted.

Blue Current never turns a missing result, expected behavior, or plausible metric into a PASS.

Each result stores:

- scenario
- PASS / FAIL
- actor / timestamp
- evidence
- recovery evidence when required
- prerequisite snapshot
- override state/reason
- observed latency
- observed errors
- observed duplicate count
- `operationalMutationPerformed: false`
- `syntheticPass: false`
