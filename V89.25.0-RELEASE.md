# V89.25.0 — Pilot Readiness & Launch Control

V89.25 converges restaurant configuration, location certification, workflow binding,
service simulation, and operator acceptance into one controlled GO / HOLD launch gate.

Active launch holds block progression. A GO-eligible assessment still cannot launch a
pilot automatically: explicit human approval is required and is bound to the exact
evidence set. Evidence changes require reapproval.

Automatic launch, automatic expansion, provider write-back, and autonomous production
changes remain disabled.
