# Blue Current V42.8.0 — Live Delivery Control

## V42.6 Source Adapter Registry
Adds provider-shaped normalization profiles for Toast POS, OpenTable reservations, generic kitchen, generic labor, and generic inventory feeds. These profiles normalize inbound payloads into Blue Current canonical events. They do not embed provider credentials or claim a live vendor connection by themselves.

## V42.7 Delivery Assurance
Adds deterministic event fingerprints and optional source event IDs to prevent duplicate ingestion. Duplicate deliveries are acknowledged without being stored twice. Accepted, rejected, replayed, and duplicate counts are retained per connector.

## V42.8 Ingestion Observability
Adds per-source ingestion health, delivery counters, dead-letter visibility, source lag, and a combined health score.

## Server API
- `GET /api/live/adapters`
- `POST /api/live/adapters/:adapterId/preview`
- `POST /api/live/adapters/:adapterId/ingest`
- `GET /api/live/delivery-metrics`

All routes remain authenticated through the existing Blue Current session layer.
