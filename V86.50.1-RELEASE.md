# V86.50.1 — Global Light-Surface Typography Contrast Hardening

This hotfix replaces screen-by-screen typography patches with a computed contrast
guard.

At runtime Blue Current measures rendered foreground/background contrast for text
elements. If an element is genuinely displayed on a light surface and fails readable
contrast, it receives the final dark-ink contract. Dark surfaces are not recolored.

The guard covers legacy and dynamically rendered screens, including headings, body
copy, metrics, labels, forms, buttons, table text, placeholders, and responsive views.
