# BLUE CURRENT V51.50.0 — PILOT DEPLOYMENT PACKAGE

V51.46–V51.50 packages Blue Current for controlled restaurant pilot deployment without automatically deploying or going live.

## Deployment package checklist

Each in-scope restaurant is evaluated against 10 deployment-package requirements:

1. LOCATION_CONFIG
2. ENVIRONMENT_PREFLIGHT
3. ACCESS_PACKAGE
4. CONNECTOR_CHECKLIST
5. BACKUP_RESTORE
6. STARTUP_RESTART
7. SUPPORT_ESCALATION
8. ROLLBACK
9. DEPLOYMENT_MANIFEST
10. DEPLOYMENT_EVIDENCE

## Location configuration package

- restaurant/location identity

- release version
- target environment
- support owner

- human package evidence

## Environment / preflight

The deployment manifest explicitly requires:

- repository validation
- V51.50 focused deployment-package regression
- V51.45 executive-accuracy regression
- runtime start
- health endpoint verification

Expected health version:

`51.50.0`

## Backup / restore

Backup procedure:

- stop runtime
- copy the configured Blue Current database to a protected timestamped backup
- verify SHA-256
- restart

Restore procedure:

- stop runtime
- preserve failed database/log evidence
- restore the verified backup
- restart
- verify health and authentication

## Startup / restart

Startup:

- `npm run check`
- `npm run start`
- verify `/api/health`
- confirm expected version before operator login

Restart:

- terminate Node cleanly
- validate
- restart
- verify health/auth
- reopen pilot surface

## Support / escalation

The package requires explicit:

- pilot support owner
- technical escalation owner
- issue timestamp/location/workflow evidence
- guest/service impact record
- immediate escalation for access/security/data-integrity issues

## Rollback

Rollback is defined for:

- reproducible pilot-blocking regressions
- data-integrity risk
- authorization regression
- unrecoverable startup/runtime failure

Rollback does not occur automatically.

## Human deployment evidence

Package generation requires human evidence.

Final deployment certification requires:

- all 10 package checks complete
- human certification evidence
- human certification note
- admin permission

Certified state:

`PILOT_DEPLOYMENT_CERTIFIED`

Certification does not perform deployment or go-live.
