# V100.2.4 — Reservation Readability

## Purpose
Normalize reservation-row presentation after V100.2.3 proved the transaction and workspace lifecycle but exposed washed-out/low-contrast reservation content.

## Changes
- Gives the Reservations panel explicit dark-surface ownership.
- Normalizes static and newly-created reservation rows to the same dark presentation.
- Raises contrast for guest name, time, party/preferences/notes, status badge, and Details action.
- Preserves existing Host Stand data and interaction logic.

## Non-goals
No changes to reservation persistence, transaction logic, authentication, Command, navigation, server routes, database, RBAC, or shell ownership.
