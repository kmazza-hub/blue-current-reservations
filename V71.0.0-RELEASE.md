# V71.0.0 — Persistence Abstraction & Transactional Database Migration Readiness

V71 removes the production server's direct dependency on the JSON database implementation.

## New persistence architecture

Production construction is now:

`Persistence adapter -> PersistenceGateway -> Blue Current services`

The shipped adapter remains the durable JSON implementation, so restaurant behavior does not change in this wave.

Current driver:
- `json`
- topology: `single-node-durable-json`

The gateway preserves the existing service-facing methods:
- read / reload
- list / get
- create / update
- mutate / write
- verified backup / recovery diagnostics
- persistence drain

## Transaction contract

V71 adds:

`database.transaction(work, metadata)`

The unit-of-work API supports multi-collection:
- list / get
- create / update / remove
- direct collection access for migration-safe transitional work

The JSON adapter executes the transaction inside its serialized durable mutation queue. If the work throws, none of the transaction state is persisted.

This gives Blue Current an explicit transaction boundary before a managed relational adapter is introduced.

## Managed database migration readiness

Admin-only:

`GET /api/system/persistence-readiness`

reports:
- active persistence driver
- topology and capabilities
- transaction capability
- persisted collection/document inventory
- shape fingerprints
- migration blockers
- managed transactional migration strategy

A migration plan is included at:

`config/persistence/V71.0-managed-transactional-migration.json`

The planned path is:
1. persistence contract — complete
2. transaction boundaries — complete
3. schema catalog — complete
4. managed adapter
5. schema mapping
6. verified backfill
7. shadow reads
8. dual writes
9. human-certified cutover
10. reversible rollback window

V71 does not install PostgreSQL and does not perform an automatic migration or cutover.

## Driver selection

`BLUE_CURRENT_PERSISTENCE_DRIVER=json`

Unknown/uninstalled drivers fail closed with `PERSISTENCE_DRIVER_NOT_INSTALLED`; Blue Current never silently falls back to JSON after a managed driver was requested.
