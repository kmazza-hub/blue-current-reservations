# V95.75.0 — Pilot Exit Readiness & V96 Certification Preparation

V95.75 is the final pre-V96 consolidation gate. It combines repeated-service confidence, pilot
stabilization/closeout evidence, unresolved debt and incident closure, operator/guest/support/KPI
evidence, and the existing immutable release-candidate review.

A location and release candidate must satisfy all required evidence before the system reports
READY_FOR_V96_CERTIFICATION. This wave does not itself certify V96; certification remains an explicit
human action and does not deploy, start runtime, or expand locations.

Next gate: V96 Pilot-Ready Certification.
