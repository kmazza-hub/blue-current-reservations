# V100.2.1 — Command Presentation State Ownership

## Why this repair exists
V100.2.0 correctly restored canonical shell visibility, but the global light-surface contrast guard could misclassify text inside the Hospitality OS dark gradient shell because it evaluates `backgroundColor` and cannot infer gradient luminance. That caused dark-on-light corrective ink to be applied to dark Command panels.

## Repair
- Explicitly excludes `#blueCurrentCommand`, `.bc-os-shell`, and surfaces marked `data-bc-surface-tone="dark"` from automatic dark-on-light recoloring.
- Preserves the light-surface contrast guard everywhere else.
- Existing erroneous `bc-auto-light-contrast` classes are removed during the guard's normal evaluation because those Command descendants now resolve to `requiresFix === false`.

## Scope
Client presentation only. No auth, API, routing, server, database, persistence, RBAC, or commercial governance changes.
