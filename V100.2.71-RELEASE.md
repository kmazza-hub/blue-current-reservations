# V100.2.71 — Manager Action Follow-Up Intelligence

## Objective
Answer a restrained manager question: **What real open action has remained unresolved long enough that it deserves another look?**

## Truth boundary
V100.2.71 does not parse free-form due text or invent an overdue state. A follow-up review candidate must:

- still be open;
- have a valid `createdAt` timestamp;
- have been created at least 30 minutes ago.

The UI explicitly describes this as a review signal, not an overdue diagnosis.

## Runtime discipline
No new polling, interval, or MutationObserver is introduced. V100.2.68 emits one narrow render event; V100.2.71 responds to it and remains lazy-loaded with the Manager workspace.

## Protected behavior
No Floor, Reservation, Waitlist, Guest, Service, Kitchen, Staffing, Time Clock, or Manager Action mutation lifecycle is changed by the follow-up module.
