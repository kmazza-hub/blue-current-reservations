# Blue Current V100.3.38 — Operational Lifecycle Stress Certification

This wave adds a destructive-safe, authenticated certification of the connected frontline restaurant lifecycle.

## Certified journey

- Two independent authenticated operator sessions
- Reservation creation and arrival
- Seating into an available table
- Safe replay of a repeated Seat action
- Immediate Floor truth visible to the second session
- Service creation, ready state, delivery, and reservation completion
- Table release after completed service
- Walk-in waitlist creation and seating
- Clock in, safe repeated Clock In, break start/end, and clock out
- Server restart with reservation, Floor, waitlist, and timecard state preserved

## Safety

- The certification copies the stable seed into a unique operating-system temporary directory.
- It launches an isolated server on a high random port.
- It never opens or changes `database/data/blue-current.json`.
- It stops the isolated server and removes its temporary database after completion.

No production UI or runtime database file is changed by this wave.
