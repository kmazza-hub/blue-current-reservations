# Blue Current V100.3.7 — Portaled Operator Workspaces

Physical testing of V100.3.6 showed that fixed-position focused targets could still be blank or land on unrelated content because the live targets remained inside transformed/hidden/scrolling page ancestors. Back also exposed whatever long-page hash/scroll state was underneath.

## Correction
- Find Guest, Service, Kitchen and Staff targets are now physically portaled into a body-level fixed stage while active.
- The live DOM node is moved, not cloned, so existing event listeners and current state remain intact.
- On exit, the node is restored to its exact original DOM position.
- Back / Exit returns to a deterministic Host Stand home context instead of revealing an arbitrary underlying scroll position.
- Full-screen Floor uses the same body-level portal approach so it can truly own the software viewport.
- Seat continues to enter Floor focus automatically.

## Scope guard
No server, auth, API, reservation, seating, service truth, kitchen truth, staffing truth, or database semantics changed.
