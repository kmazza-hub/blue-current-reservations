# V90.75.0 — Operator Pilot Control Actions

The controlled-pilot Command surface now exposes the human actions required during a
restaurant pilot: start, pause, resume, stop, acknowledge, escalate, and resolve.

These controls reuse the certified V89 runtime and incident guardrails rather than creating
a second control path. Start still requires current launch approval; pause/stop require a
meaningful reason; resume rechecks the approved operating envelope; critical auto-pause
remains intact. The UI reports blocked actions directly to the operator.

No automatic session start, provider write-back, pilot expansion, or autonomous production
change is introduced.
