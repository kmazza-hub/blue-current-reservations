# Physical iPad Walkthrough

1. Start with `npm run pilot:lan` and open the printed address on the iPad.
2. Sign in as an administrator, append `?pilotAcceptance=1` to the address, and reload.
3. Enter the operator, device, iPadOS, and Wi-Fi identity.
4. Complete every named job, return to the walkthrough, add a meaningful note, and choose Clear, Friction, or Blocked.
5. Repeat against the stable hosted-pilot URL using Hosted pilot before final acceptance.
6. Record final acceptance only when every server-side gate is ready.

The console does not approve itself and does not treat automated testing as physical evidence.
