# V78.75.0 — Authentication & Session Lifecycle Hardening

V78.75 finishes the authentication cleanup exposed during V78.50 testing.

## Command request lifecycle
- `refreshCommand()` itself checks shared authenticated app state.
- No workspace can bypass the auth gate.
- rapid duplicate refreshes are coalesced.
- session restore, sign-in, and organization switch each trigger one fresh Command read.
- sign-out returns Command to the protected access state.

## Focus-safe auth dialog
The authentication overlay now has one lifecycle controller.

Open:
- remove `aria-hidden`
- remove `inert`
- open dialog
- focus email

Close:
- move focus outside the dialog first
- close dialog
- set `aria-hidden=true`
- set `inert`

The startup loader now uses this same controller instead of independently hiding a focused auth dialog.

## Security
Server authorization is unchanged. This wave coordinates the client lifecycle and removes redundant unauthorized requests; it does not weaken protected APIs.
