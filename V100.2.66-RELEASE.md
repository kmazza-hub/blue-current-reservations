# V100.2.66 — Published Shift Attendance Exceptions

Adds person-level staffing attendance truth.

- Uses only published active shifts.
- Uses employee identity from Scheduling.
- Uses active Time Clock employee IDs as attendance truth.
- Applies a restrained 10-minute grace period.
- Oldest attendance exception becomes the priority.
- Says only that no active clock-in is recorded.
- Does not label employees as callout/no-show and does not mutate scheduling or timekeeping state.
