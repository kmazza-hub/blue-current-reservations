# BLUE CURRENT V47.10.0 — HOSPITALITY ACTION WORKSPACE

## Scope

V47.06–V47.10 closes the first execution loop introduced by Hospitality Performance Command.

V47.05 answered:

`What should the manager act on first?`

V47.10 now answers:

`Who owns it, what exactly are we trying to accomplish, when should it be resolved, and where is the action right now?`

## V47.06 — Opportunity-to-Action Conversion

The **Own Action** decision in Hospitality Performance Command now creates an operating workspace for that opportunity.

The workspace captures the opportunity at acceptance time rather than relying on the signal remaining unchanged later.

Captured fields include:
- opportunity ID
- title
- category
- severity
- reason
- next action
- owner
- confidence
- estimated impact
- impact label
- source metadata
- priority score

Duplicate protection prevents the same unresolved opportunity from creating multiple active workspaces.

## V47.07 — Baseline + Target

Each action records a baseline at creation:
- creation timestamp
- opportunity score
- source metadata
- expected financial impact

Each action also receives:
- target metric
- target value
- target time

Category-aware default targets are provided for:
- kitchen
- reservations
- labor
- inventory
- guests
- revenue

## V47.08 — Ownership + Execution State

Action states:
- accepted
- in_progress
- blocked
- completed
- cancelled

Managers can:
- start an action
- mark it blocked
- complete it
- cancel it
- change the owner
- add an operating note

Every transition is timestamped and appended to the action update history.

## V47.09 — Accountability + Audit Trail

Action creation and state changes:
- persist in the Blue Current database
- write to the audit ledger
- emit realtime events

The Action Workspace summarizes:
- active actions
- blocked actions
- overdue actions
- active expected impact
- completed actions

## V47.10 — Action Workspace UI

Adds **Action Workspace** immediately below Hospitality Performance Command.

Each workspace shows:
- category
- status
- age
- title
- why it matters
- prescribed action
- owner
- target metric
- target state
- deadline
- expected impact
- update count
- execution controls

The workspace refreshes after action creation, action updates, and authentication restoration.

## Safety

This remains a manager-controlled execution layer.

Policy:
- `humanOwned: true`
- `automaticExecution: false`

Blue Current records and measures the manager's operating action. It does not automatically change restaurant operations.

## API

### GET
`/api/hospitality-actions?locationId=<location>`

Returns the location action workspace and summary.

### POST
`/api/hospitality-actions`

Creates an action from a currently active Hospitality Performance opportunity.

### PATCH
`/api/hospitality-actions/:workspaceId`

Updates status, ownership, target data, and notes.

All endpoints require authentication. Writes require write/admin permission.
