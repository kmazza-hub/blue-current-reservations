# Blue Current V100.2.16

## Generic Guest Action Context + Host Stand Contrast Polish

This release removes the remaining Anthony-specific Host Stand behavior from the operator-facing floor workflow and introduces a generic active-party context.

### Operator behavior
- Reservation, waitlist, and guest rows open one simple editable detail surface.
- Expected reservations can be marked arrived or have a table held.
- Arrived reservations can enter the floor and choose a table for one-tap confirmed seating.
- Floor table clicks are neutral unless an active guest workflow owns them.
- Existing guided waitlist seating remains in place.
- Seat-confirmation and Cancel controls receive explicit high-contrast styling.

### Product rule
**Aim small, miss small. Who am I helping? What do they need? Where are they going?**
