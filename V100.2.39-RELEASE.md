# V100.2.39 — Collision-Safe Premium Floor Layout

## Goal
Guarantee that visible table furniture never overlaps in the premium 36-table host-stand demo.

## Changes
- Main Floor: 16 tables assigned to a clean 4 × 4 physical slot system.
- Waterfront: 12 tables assigned to three separated rows.
- Private Dining: 8 tables assigned to two separated rows.
- Capacity labels remain centered and constrained.
- Selected-table growth reduced slightly to prevent highlight collisions.
- 6-top and 8-top maximum visual widths tightened for dense iPad layouts.

## Non-goals
No behavioral changes to seating, waitlist, arrivals, reservations, counts, prediction, or persistence.
