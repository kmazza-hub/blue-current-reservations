# V100.2.46 — Guest Recognition & Hospitality Memory

Turns the Guest workspace into a faster recognition layer without changing live Floor, Waitlist, Reservations, seating, or table lifecycle behavior.

- Classifies first-visit, returning, and regular guests from recorded visit history.
- Surfaces anniversary, birthday, VIP, dietary, accessibility, and child-seating context from existing guest memory.
- Adds a quiet Recognition card to Guest details with one immediate hospitality cue.
- Shows Returning / Regular recognition in Guest search results when applicable.
- Uses the existing deduplicated guest registry; no second guest store is introduced.
