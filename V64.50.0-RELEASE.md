# BLUE CURRENT V64.50.0 — WORKFLOW REDUCTION & ONE JOB / ONE HOME

Focused workflow-simplification wave.

The audit found that Blue Current had accumulated multiple navigation layers and repeated routes to the same operator jobs. The underlying capabilities remain valuable; the problem was forcing the operator to decide where to go before they could decide what to do.

V64.50 establishes a canonical workflow rule:

- Add walk-in -> Floor / Waitlist
- Add reservation -> Reservations
- Find guest -> Guest search
- Solve staffing -> Staff
- Fix kitchen pressure -> Kitchen
- Run service -> Service Coordination
- Ask Blue Current -> AI Brain
- Leadership decision -> Executive

Changes:
- retires the redundant sticky "Go to" workspace bar
- keeps the primary top navigation as the single workspace-navigation layer
- adds one compact Quick Jobs menu in the operator utility bar
- introduces `window.BlueCurrentWorkflows.open(job)` as the canonical in-product workflow router
- automatically opens the correct Host sub-view for walk-ins, reservations, and guest search
- reuses existing tools/advanced reveal logic when a canonical destination is hidden
- de-emphasizes deeper Command Center analytics CTAs when a primary operational path already exists

No workflow, API, data model, or operator capability is deleted.
