# Blue Current V100.3.41

## Pilot Configuration Truth Gate

V100.3.41 prevents placeholder or unverified restaurant configuration from receiving pilot certification.

### Integrity changes

- Unpersisted defaults are explicitly reported as not ready.
- Pilot configuration requires recorded real-restaurant confirmation, including verifier, timestamp, and source.
- Placeholder location identity is an explicit certification blocker.
- Configured location identity must match the organization's operational location record.
- The configured table map must match the operational table IDs, names, capacities, and complete table count.
- Any saved change after certification requires recertification.
- Provider write-back and autonomous production changes remain forced off.
- Restores the shared size-limited JSON request reader for pilot and integration write routes that referenced its legacy compatibility name.

### Data boundary

This release does not insert Chefs International restaurant facts. The intake worksheet is intentionally blank, and the certification test uses an isolated copy of the development seed database.

### Rollback

Revert the two configuration-service changes and remove the V100.3.41 certification/test documents. No database migration or operational-data rollback is required.
