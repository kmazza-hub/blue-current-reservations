# BLUE CURRENT V46.25.0 — REVERSIBLE DEPRECATION MANIFEST

## Release scope

V46.21–V46.25 acts on the operator consolidation scorecard while keeping every removal decision reversible.

### V46.21 — Verified Navigation Cleanup

The desktop navigation had 29 entries with 5 true excess duplicates.

This release removes only those verified duplicate links:
- Autonomous duplicate entries
- Guests duplicate entry
- Executive duplicate entry
- AI Brain duplicate entry

Result:
- 24 desktop navigation entries
- 24 unique desktop destinations
- 0 internal desktop-navigation duplicates

Mobile navigation was already internally unique and was not altered.

### V46.22 — Merge-Candidate Primary Routing

The consolidation engine now resolves mapped merge candidates to their primary surface.

Example:

`reservationYieldCenter → reservationOperationsCenter`

Task/use evidence generated from a merge candidate can therefore be attributed to the primary operator surface instead of creating fragmented analytics.

### V46.23 — Task-Completion Instrumentation

Adds `recordTaskCompletion()` to operator consolidation evidence.

A task completion records:
- primary surface
- source surface
- task ID
- outcome
- active role
- timestamp
- metadata

This extends the prior open-event evidence into actual task-completion evidence.

### V46.24 — Minimum Evidence Thresholds

Adds explicit review thresholds:
- 3 observed days
- 3 open events
- 1 task completion
- 1 distinct role
- 100% manager primary-workflow coverage
- automatic deletion disabled

These thresholds are review criteria, not deletion triggers.

### V46.25 — Human-Approved Deprecation Manifest

Adds a reversible manifest workflow:

1. Build draft manifest from current deprecation candidates.
2. Review evidence and primary-workflow coverage.
3. Require explicit human approval.
4. Optionally enable a reversible hide-preview feature flag.
5. Disable preview to immediately restore hidden surfaces.

The manifest policy is:

`human-approved-reversible-hide-before-delete`

Automatic deletion remains disabled.
