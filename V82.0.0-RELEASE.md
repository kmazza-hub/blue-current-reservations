# V82.0.0 — Pilot Executive Review & Expansion Decision Gate

Combines multi-shift pilot performance, evidence integrity, incident status, and
operator review into a formal executive pilot assessment.

Advisory recommendations:
- CONTINUE_PILOT
- EXPAND
- HOLD
- RETIRE

Expansion requires repeatable improvement, verified evidence, no critical
incident blocker, and completed operational/staff/guest/support review.

The recommendation is advisory. Final decisions require explicit human action.
An EXPAND decision does not itself authorize multi-location rollout or autonomous
production changes.
