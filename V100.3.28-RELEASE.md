# Blue Current V100.3.28 — Core Operations API Location Safety

This wave moves location integrity behind the interface and into the authenticated manager/command API boundary.

- Operations-feed, manager-action, service-exception, Command Center, and shift-handoff requests now require an explicit restaurant.
- Missing restaurant identity returns a clear `400` response instead of silently writing or reading Marina data.
- Every supplied restaurant continues through the existing operator authorization check.
- Shift-handoff acknowledgement now verifies both organization ownership and location authorization before mutation.
- Existing Blue Current browser clients already provide the active restaurant, so normal frontline behavior is preserved.
- No database or restaurant records are included in this release.
