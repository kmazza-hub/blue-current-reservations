# Blue Current V100.3.27 — Development Data Location Safety

This wave closes two remaining paths where development tools could silently create Marina-scoped data while another restaurant was active.

- Data Intake Sandbox samples now use the active frontline restaurant.
- Canonical Event Gateway samples now use the active frontline restaurant.
- Manual canonical ingestion requires an explicit location and confirms that it is authorized for the current operator.
- Both browser assets receive new cache keys.
- No database or restaurant records are included in this release.

Validation: focused V100.3.27 gate, full project check, cumulative location-continuity regression chain, and live-server asset smoke test.
