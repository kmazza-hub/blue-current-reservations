# V91.0.0 — Field Operator Workflow & Service-Night Polish

V91 focuses on using Blue Current under restaurant pressure rather than adding another
major subsystem.

The controlled-pilot Command surface now keeps operating state, priority, and session
elapsed time above the fold; increases touch targets for tablet/mobile use; makes STOP
visually distinct; uses explicit confirmation for START/PAUSE/STOP; requires reasons for
PAUSE and STOP; and provides immediate blocked-action feedback.

No new authority path is introduced. All actions continue through the existing certified
runtime and incident guardrails.
