# V100.3.52 — Backend Presentation Stabilization

This forward-only wave converts the live backend audit findings into guarded presentation behavior.

## What changed

- Removed embedded demo credentials from the sign-in form.
- Rejects empty sign-in submissions before any API request.
- Verifies the returned session before opening protected application surfaces.
- Makes the complete application inert and hidden from assistive technology while authentication is open.
- Prevents the owner wildcard permission (`*`) from appearing as a restaurant identity.
- Stabilizes workspace transitions out of focused operator and full-screen floor modes.
- Aligns startup diagnostics with the authoritative build marker and replaces internal module-name dumps with counts.
- Adds an accessible diagnostics name and a social preview image.

## Boundary

This release improves controlled demonstration safety and presentation quality. It does not convert a temporary `trycloudflare.com` tunnel into production hosting, connect a live restaurant provider, or certify physical iPad acceptance.
