# V76.50.0 — Command Prioritization & Manager Decision Layer

V76.50 converts verified Command signals into a ranked manager focus list.

## Ranking dimensions
Each candidate signal is scored using:
- severity
- time sensitivity / urgency
- guest impact
- service risk
- relative financial exposure when forecast context exists

Financial exposure is a relative heuristic score, never a dollar-risk claim.

## Noise suppression
Related kitchen signals are correlated into one higher-value operating priority. Command surfaces only the top three priorities and defers lower-value signals.

## Manager context
Each priority includes:
- rank
- overall score
- urgency score
- guest-impact score
- service-risk score
- financial-exposure score when available
- evidence
- suggested owner
- human-reviewed recommendation
- confidence

Historical/demo data reduces prioritization confidence and is labeled accordingly.

## Authority boundary
This layer ranks and recommends only.
- no automatic restaurant action
- no autonomous operational decision
- no automatic mutation
- manager confirmation required
