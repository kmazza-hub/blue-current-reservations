# V93.25.0 — Pilot Backup, Restore & Rollback Readiness

V93.25 certifies Blue Current's existing durable JSON recovery system for the live pilot.
It requires a verified pre-change checkpoint, checksum-verified restore sources, newest-good
backup preference with previous-good fallback, forensic preservation of corrupt primaries,
and explicit reconciliation for ambiguous mutations. Rollback remains human-approved and
must be followed by verification.
