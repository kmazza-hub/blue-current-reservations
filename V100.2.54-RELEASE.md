# V100.2.54 — Service Priority & Pacing

Turns Service milestones into an operator-priority system without touching floor presentation.

- Active Service tables are automatically ordered with overdue work first.
- Attention thresholds are stage-aware: greet 3m, ordering 7m, food delivery 15m, dining/check progression 45m, check completion 10m.
- The summary becomes **Needs attention**, not only Needs greeting.
- Overdue rows retain the restrained attention treatment and receive a concise label.
- One table / one state / one obvious next action remains intact.
- V100.2.53 room isolation and V100.2.48 floor readability are protected by an apply-time guard.

Architecture change: this release is a guarded in-place Service patch. It does not ship or overwrite the full floor controller.
