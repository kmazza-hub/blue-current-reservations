Completes the active management-location continuity chain and aligns the public product story with the current pilot phase.

- Routes Workforce Intelligence reads, recommendation decisions, and labor-plan updates through the shared authorized restaurant selection.
- Removes the final fixed-Marina request path from the active Workforce Intelligence module.
- Adds a clear public product-status section to the Blue Current marketing site.
- Describes the working Hospitality OS scope without claiming that the private pilot environment is already live.
- Identifies private staging as the next deployment environment.
- Reserves `app.bluecurrentco.com` for certified operator access while explicitly labeling it unavailable to the public.
- Adds desktop and mobile navigation access to the pilot-status explanation.

## Preserved

- Server-side location authorization remains authoritative.
- Marina remains the compatibility fallback before shared authority initialization.
- Existing public demonstrations and illustrative-data disclosures remain intact.
- This release does not deploy a backend, publish a staging environment, or alter live restaurant data.
