# V100.3.49 — Hosted Data Provisioning

This wave closes the empty-volume first-start gap without packaging or inventing restaurant data.

- Adds `npm run hosted:provision` for one-time, human-directed import into external persistent storage.
- Requires an explicit source and an absolute target outside the repository.
- Validates required database collections and rejects plaintext credentials.
- Writes owner-only data, verifies staged bytes, and records a SHA-256 provisioning manifest.
- Refuses every overwrite and supports independent `--verify` checks before startup.

No live database, seed database, secret, deployment, DNS change, or automatic restore is included.
