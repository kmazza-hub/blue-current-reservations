# V100.2.67 — Staffing Rush-Condition Certification

Certifies staffing truth under multiple simultaneous employees and roles.

The contract verifies:

- role coverage stays isolated by role;
- a break removes active coverage without creating a false person-level absence;
- only a genuinely missing active clock-in creates an attendance exception;
- one employee clocking in clears only that employee's attendance exception;
- duplicate active identity cannot create a second employee identity;
- Staffing remains read-only over Scheduling and Time Clock state;
- Host/Floor remains protected.

No runtime application files are modified.
