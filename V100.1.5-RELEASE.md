# V100.1.5 — Command Auth Presentation Synchronization Hotfix

## Purpose

Fix the final presentation mismatch discovered during the V100 Operational Audit: the authoritative authentication coordinator could report an authenticated operator while Command still rendered a visible **Sign in** CTA.

## Changes

- Makes the authoritative auth-session coordinator control Command authentication presentation.
- Prevents Command from rendering auth-required mode while the coordinator reports an authenticated session.
- Hides the Command **Sign in** CTA whenever the operator is authenticated.
- Also hides the **Sign in** CTA during transport/reconnecting states, so connectivity degradation cannot masquerade as an authentication problem.
- Preserves server-authoritative protected Command requests and existing 401/session-expiry handling.
- Advances only the operator-shell repair marker to `100.1.5`; the certified commercial package remains `100.0.0`.

## Scope

No database, persistence, RBAC, server-authentication, or commercial-release-governance changes.
