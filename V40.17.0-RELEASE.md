# Blue Current V40.17.0 — Trust, Routing & Safety

## V40.15 Knowledge Source Registry
Registers agent-readable sources with ownership, trust level, lifecycle status, and purpose.

## V40.16 Model Routing Control
Routes requests to fast, balanced, or deep reasoning profiles based on task risk, complexity, and latency needs. High-risk or write-capable requests require human approval.

## V40.17 Agent Safety Test Suite
Runs deterministic governance checks covering approval boundaries, trusted grounding, high-risk routing, named ownership, and no automatic execution.

This release adds governance infrastructure only. It does not transmit credentials, invoke an external model provider, or execute restaurant actions automatically.
