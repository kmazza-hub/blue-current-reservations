## Human operating decision

The launch owner/executive can record:

- CONTINUE
- HOLD
- ROLLBACK

CONTINUE normally requires:

- all seven first-live milestones
- a fully healthy latest observation
- zero high/critical incident observations

An executive can still record CONTINUE with open criteria only with a documented reason.

HOLD and ROLLBACK always require a human reason.

## Important separation

A ROLLBACK decision is a human recommendation/decision record.

It does not execute rollback.

V51.60 does not:

- start the runtime
- make the first reservation
- seat a guest
- advance service flow
- change kitchen state
- contact guests
- automatically mitigate incidents
- automatically roll back production
