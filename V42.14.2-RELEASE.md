# Blue Current V42.14.2 — Windows / OneDrive Database Reliability Hotfix

This hotfix hardens the JSON persistence layer against transient Windows file locks observed when the repository lives under OneDrive.

## Changes

- Unique per-write temporary files instead of one shared `blue-current.json.tmp`.
- Serialized public writes and mutations.
- A failed mutation no longer poisons the write queue.
- Exponential retry/backoff for `EPERM`, `EBUSY`, `EACCES`, and `ENOTEMPTY`.
- Durable temp-file flush before replacement.
- Controlled copy fallback when Windows blocks atomic rename-over-existing.
- Last-known-good `.bak` preservation before fallback replacement.
- Best-effort cleanup of stale temp/fallback files.
- Explicit server-side request error logging.
- Server runtime label updated to V42.14.2.

No frontend module or live-event contract behavior is changed.
