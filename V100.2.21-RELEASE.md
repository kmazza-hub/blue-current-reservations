# V100.2.21 — Host Stand Contrast Hardening

## Purpose
Restore service-distance readability to the recovered Host Stand without touching the now-stable runtime or seating transaction flow.

## Changes
- Strong dark-on-light contrast for all Cancel controls.
- Strong dark copy on the white seat-confirmation card.
- Brighter white instruction text on the choose-table banner.
- Stronger primary Seat confirmation treatment.
- More obvious available-table highlight and stronger unavailable-table suppression.
- Stronger Ready-to-seat source and priority chips.

## Non-goals
No changes to guest lifecycle, queue ordering, table assignment, seating ownership, persistence, authentication, or runtime observer behavior.
