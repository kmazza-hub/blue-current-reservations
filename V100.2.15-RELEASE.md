# V100.2.15 — Host Stand Readability + Guided Waitlist Seating

## Product principle
**Aim small, miss small.** One guest, one decision, one obvious next action.

## Changes
- Enlarges and strengthens Waitlist/Arrivals typography and primary actions.
- Replaces instant Waitlist seating with a guided transaction: Seat → choose table → confirm.
- Prevents legacy Seat handlers from marking a guest seated without a table assignment.
- Synchronizes the chosen table, waitlist count, seated count, and sidebar counts.
- Collapses the Anthony reservation detail card after a successful table hold.
- Preserves V100.2.13 reservation arrival/seating behavior and V100.2.14 workspace simplification.
