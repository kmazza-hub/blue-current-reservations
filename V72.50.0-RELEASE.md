# V72.50.0 — Backend Service Contracts & Cross-Module Data Integrity Certification

V72.50 returns from migration infrastructure to the operating core of Blue Current.

## Persistence service-contract closure

A code audit found two real service calls outside the persistence contract:
- `inventoryIntelligenceService -> database.insert`
- `actionListService -> database.delete`

V72.50 adds `insert` and `delete` to DatabaseService, the JSON adapter, PersistenceGateway, and the formal persistence contract. The backend contract audit now reports zero unknown persistence calls.

## Tenant-safe operational mutations

High-risk operational mutations are hardened so an ID alone is never enough to mutate another organization's record.

Certified boundaries:
- Floor table updates
- Waitlist seating
- Staff updates
- Section assignment
- Table reassignment
- Kitchen ticket updates
- Kitchen item updates
- Kitchen ticket creation / station ownership
- Purchase-order vendor/item ownership
- Executive goal updates

Floor/staff/kitchen compound mutations use the V71 transaction boundary where appropriate.

## Cross-module data-integrity certification

New read-only integrity engine validates:
- organization/location ownership
- orphan references
- floor/workforce assignments
- reservation/table relationships
- waitlist/table relationships
- kitchen/station relationships
- inventory/vendor relationships
- recipe/inventory relationships
- purchase-order references
- non-negative inventory/purchase values
- financial numeric integrity

It never performs automatic repair.

Endpoint:

`GET /api/system/operational-data-integrity`
