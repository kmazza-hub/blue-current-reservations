# V95.0.0 — Pilot Launch-Day Command & Control

V95.0 turns the certified readiness stack into a launch-day operating picture. The command gate
combines final GO/HOLD eligibility with the existing live-pilot shift command, runtime session,
incident, fallback, and closeout controls. Operators can see pre-shift readiness, human start/close
requirements, incident posture, critical-pause posture, and local fallback availability in one gate.

The assessment never starts a shift. Critical runtime incidents retain the existing automatic safety
pause, while launch, resume/stop decisions, rollback, and closeout remain human-directed.
