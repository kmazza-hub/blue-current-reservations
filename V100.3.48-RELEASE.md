# V100.3.48 — Hosted Deployment Handoff

This wave turns the already-certified production boundary into a provider-neutral deployment package for `app.bluecurrentco.com`.

- Adds a non-root Node 22 production container.
- Requires a persistent `/var/lib/blue-current` volume and one application writer.
- Excludes live data, backups, secrets, local environment files, and Git history from the image.
- Adds a platform health check against `/api/health`.
- Adds an explicit production environment contract and `npm run hosted:preflight` fail-closed validation.
- Preserves graceful shutdown and the verified recovery-backup chain.

This release does not select a hosting vendor, modify DNS, upload secrets, deploy the app, or activate a pilot.
