# BLUE CURRENT V48.5.0 — PILOT VALUE SCORECARD

## V48 direction

V47 proved that Blue Current can detect operating opportunity, create manager-owned actions, measure outcomes, model controllable profitability, predict service constraints, run the management rhythm, and rank a restaurant portfolio.

V48 begins the commercial proof layer.

The first question is:

`Is the pilot actually creating measurable value?`

## V48.01 — Explicit Pilot Baseline

Adds `PilotValueScorecardService`.

A pilot cannot claim value until an explicit baseline is captured.

The baseline records the authorized portfolio's current:

- restaurant count
- average readiness
- average Manager Operating Rhythm score
- modeled controllable contribution
- modeled leakage
- realized action impact
- active action count
- urgent predictive interventions
- high / watch attention locations

It also stores per-location baseline values for readiness, rhythm, leakage, and controllable contribution.

## V48.02 — Pilot Targets

The pilot baseline stores explicit targets.

Default 30-day targets:

- +5 readiness points
- +20 Manager Operating Rhythm points
- 10% modeled leakage reduction
- 60% action realization-rate target

Pilot duration is configurable from 7–180 days.

Targets can be set before the pilot rather than invented after results are known.

## V48.03 — Honest Value Attribution

Blue Current now separates two kinds of pilot evidence.

### Verified realized value

Only realized impact already measured through completed Blue Current Action Workspace outcomes counts as:

`verifiedRealizedImpactDollars`

### Observed but not automatically attributed

The scorecard separately shows:

- controllable contribution movement
- modeled leakage reduction
- readiness lift
- operating-rhythm lift

These are evidence of operating movement during the pilot, but the system does not claim Blue Current alone caused them.

Policy:

- `verifiedValueRequiresMeasuredOutcomes: true`
- `counterfactualClaims: false`
- `automaticAttribution: false`

## V48.04 — Pilot Scorecard

The executive scorecard contains:

- overall pilot score
- adoption score
- operating score
- value-evidence score
- targets met
- verified realized value
- modeled leakage reduction
- readiness lift
- Manager Operating Rhythm lift

The scorecard is designed to answer whether the pilot is building evidence toward commercial success without turning modeled operational exposure into fake ROI.

## V48.05 — Value Checkpoints

Adds checkpoint persistence so ownership can capture pilot progress over time.

Each checkpoint stores:

- current portfolio state
- value evidence
- pilot scorecard
- manager/executive note
- actor
- timestamp

This creates a historical commercial-proof record rather than a single current-state dashboard.

## API

### GET
`/api/pilot-value-scorecard`

Returns the current pilot scorecard or `baseline-required`.

### POST
`/api/pilot-value-scorecard/baseline`

Captures the pilot baseline.

### POST
`/api/pilot-value-scorecard/checkpoints`

Captures a pilot value checkpoint.

Writes require write/admin permission.
