# Apply Blue Current V100.3.43

Copy the ZIP into the repository root, install dependencies, and run:

```powershell
npm run check
node .\scripts\maintenance\test-v100.3.43-pilot-release-candidate-lock.js
npm run certify:pilot
```

The package contains no database files. A successful one-command certificate locks the local software candidate; physical-iPad, actual restaurant configuration, hosting, DNS, and pilot activation remain separate human gates.
