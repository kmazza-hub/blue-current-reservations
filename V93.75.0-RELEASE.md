# V93.75.0 — Pilot Security, Access & Audit Readiness

V93.75 certifies Blue Current's established authentication, RBAC, organization/location scoping,
session controls, and audit evidence as the security boundary for the live pilot. Passwords use
scrypt with timing-safe verification; session tokens are hashed; idle/absolute expiry, revocation,
failed-login lockout, least privilege, and membership-bound organization access remain enforced.
No automatic role escalation, scope expansion, or autonomous permission changes are introduced.
