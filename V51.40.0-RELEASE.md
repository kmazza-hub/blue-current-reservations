## System evidence versus human proof

Each stage separates:

- existing system evidence
- human rehearsal/checkpoint evidence
- final human certification

A system-evidence gap does not become a pass.

A controlled rehearsal may continue through a known evidence gap only with a documented override reason.

## Existing operating systems are reused

- FloorService

## Validation edge case caught before release

The first synthetic regression fixture produced 9/10 instead of 10/10.

The certification service was correct: the fixture had historical seated-waitlist evidence, but no guest still waiting and only 50% occupancy, so there was no actual seating-pressure evidence.

The fixture was corrected to include both:

- seated waitlist-to-table continuity
- an active waiting guest

The complete clean regression was then rerun successfully.
