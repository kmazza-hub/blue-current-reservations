# V80.75.0 — Pilot Shift Certification & Go/No-Go Control

Adds a pre-service certification gate for each pilot shift.

Decisions:
- GO
- GO_WITH_CONDITIONS
- NO_GO

Hard blockers include unavailable local fallback, unresolved critical incidents,
emergency local mode, unstable provider continuity, and untrusted provider data.

Operator readiness includes a named shift lead, pre-shift briefing, rollback
procedure confirmation, and emergency contact confirmation.

NO_GO cannot be overridden by automation. Conditional GO requires explicit human
acceptance. A GO certification never enables autonomous production changes.
