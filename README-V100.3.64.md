# Blue Current V100.3.64 — Team Scheduling Usability

This forward-only update completes the requested Team usability wave.

- Team replaces the global rush bar with Employees, Availability, PTO, Schedule, Time Clock, and Punch Review actions. Leaving Team restores the normal operating bar.
- Missed-punch review uses high-contrast text, identifies affected employees and dates, and opens the first unresolved record.
- Scheduling combines both certified employee sources, excludes inactive or terminated employees, and shows eligible employee names beside Open shift.
- Schedule choices are filtered by role, saved availability, approved PTO, and overlapping shifts.
- Smart Fill uses a Blue Current confirmation panel instead of a browser popup and refreshes the schedule after assignment.

The installer requires certified V100.3.63 and verifies that the external runtime database is unchanged during installation.
