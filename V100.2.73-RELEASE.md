# V100.2.73 — Scheduling Truth Foundation

Moves horizontally into Scheduling after Manager Operations rush certification.

The primary Scheduling surface now answers **Who is scheduled to work?** from the existing Scheduling API. It distinguishes Draft from Published state, shows recorded shifts/open shifts/conflicts, and deliberately excludes AI staffing recommendations and reservation-demand assumptions from the primary operator view.

The existing scheduling service/API and legacy editor module are preserved; this wave does not rewrite scheduling persistence. The new truth surface is loaded with the existing deferred staff runtime group and introduces no interval, MutationObserver, or polling timer.
