# Blue Current V34.6.2 — Operational Context Engine

V34.6.2 extends the V34.6.1 orchestration foundation with explainable operational context.

## Added

- Operational context capture for service period, occupancy, kitchen load, waitlist, at-risk tables, labor and reservation count.
- Composite operating-pressure score and pressure band.
- Trend detection across context samples.
- Multi-factor recommendation priority scoring.
- Plain-language reasoning attached to each recommendation.
- Context-aware recommendation ordering.
- Persistent context/decision/workflow/outcome timeline.
- AI Orchestration Center context KPIs, reasoning panel and narrative timeline.

## Governance

The release remains advisory and human governed. Approval-required recommendations cannot start a workflow without an explicit manager decision.
