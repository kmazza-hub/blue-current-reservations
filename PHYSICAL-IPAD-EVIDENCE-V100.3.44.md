# Physical iPad Evidence Record

Record each workflow step twice when practical: first on LAN for isolated device validation, then on `https://pilot.bluecurrentco.com` for final acceptance.

Required for every observation:

- Environment: `LAN` or `HOSTED_PILOT`
- Workflow step: launch, reservation, arrival, waitlist, seating, floor, service, kitchen, staff, or interruption-recovery
- Outcome: `CLEAR`, `FRICTION`, or `BLOCKED`
- Acceptance dimension and 1–5 score
- Meaningful operator note
- Physical device ID and model
- iPadOS version
- Network name/type
- Named operator
- Exact configured restaurant location ID
- Evidence capture date/time

Final acceptance remains unavailable until all ten steps have hosted physical-iPad evidence, all seven dimensions are covered, no blockers remain, scores meet the threshold, and a human explicitly confirms the physical device and hosted environment.
