# Blue Current V100.3.63 — Staff Record Management

This certified update unifies the Workforce and Time Clock employee sources. All active staff now appear in the clock kiosk; legacy employee PTO can be approved or denied; and corrected open punches become completed records when management supplies a valid clock-out.

Add Employee now validates every required field inline. Managers assign or generate a unique 4–6 digit PIN, can change it later, edit role/rate/hours, end employment without deleting history, and reactivate an employee. The staff record shows average weekly recorded hours, approved sick days, attendance, and on-time percentage. Attendance and punctuality use only published shifts and recorded punches over the last 28 days; missing evidence displays a dash.

The installer requires V100.3.62, preserves the external runtime database byte-for-byte during installation, validates all source assets, and runs the complete V100.3.54–V100.3.63 certification chain.
