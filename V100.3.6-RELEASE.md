# Blue Current V100.3.6 — Focused Operator Workspaces

Physical iPad evidence showed that repeatedly correcting Safari scroll position was not deterministic. V100.3.6 removes scrolling from the four affected Quick Jobs.

## Focused operator workspaces
- Find Guest opens the guest search panel as a fixed working screen.
- Service opens the live Digital Twin application directly, without the page intro.
- Kitchen opens the Kitchen Throughput Coach directly, without governance/learning surfaces.
- Staff opens the certified live-truth staffing surface directly.
- The Rush Dock remains available and can switch directly between focused jobs.
- Back / Exit restores the prior operating context.

## Floor
- V100.3.5 full-screen Host Floor behavior is retained.
- Floor remains a true full-software-viewport workspace.
- Seat still enters full-screen Floor automatically.

## Architecture change
Quick Jobs are no longer `scrollIntoView` destinations. The actual operator surface is fixed into the usable iPad viewport, so later DOM rendering cannot move it.

## Scope guard
No server, authentication, API, reservation state, seating state, service truth, kitchen truth, staffing truth, or database semantics were changed.
