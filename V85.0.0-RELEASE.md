# V85.0.0 — Architecture Freeze & Pilot Build Baseline

V85 marks the end of major architecture expansion before the first pilot.

The current hospitality, operational, executive, learning, evidence, and governance
domains are now treated as the authoritative pilot architecture. New major capability
requires demonstrated pilot evidence. Duplicate domain authority and duplicate write
paths are prohibited.

The freeze does not stop development. It changes development priority to integration,
restaurant configuration, UX simplification, reliability/security, and pilot
certification.
