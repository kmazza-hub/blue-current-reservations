# V96.25.0 — Pilot Baseline Lock & Commercial-Hardening Entry

V96.25 protects the V96 pilot-ready milestone while opening the commercial-hardening phase. The
V96.0 baseline remains recoverable and authoritative. Defect fixes, UX simplification, reliability,
security, observability, supportability, deployment discipline, and commercial-release preparation
are explicitly allowed. Unvalidated major capabilities, duplicate authorities/write paths, and
autonomous production changes are restricted.

The gate requires a human-certified V96 pilot baseline before commercial hardening is considered
open. Next gate: Commercial Hardening Defect & Friction Control.
