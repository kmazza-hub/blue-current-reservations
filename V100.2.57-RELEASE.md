# V100.2.57 — Service Completion / Table Turn Handoff

This wave repairs the authoritative seating-to-Service link before completing the service lifecycle.

- Adds an isolated table-lifecycle bridge that observes the real Host/Floor table assignment rather than depending on older generic Seat handlers.
- Service intake now carries the actual table identity and heals a matching unlinked active Service record without resetting its stage.
- Complete service is transactional: the Service record is not cleared unless the linked floor table can safely transition.
- Completion moves the linked table from SEATED to CLEANING only. Blue Current still requires a human to confirm CLEANING to OPEN.
- Guest/table mismatch, missing table identity, or an unexpected table state blocks completion instead of silently corrupting ownership.
- Repairs the malformed V100.2.56 recovery explanation string as a forward compatibility fix.
- The protected V100.2.47 Floor restoration section is verified byte-for-byte unchanged during apply.
