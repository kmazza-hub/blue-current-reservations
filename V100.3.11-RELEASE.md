# V100.3.11 — Floor Lifecycle Certification & Cleanup

Forward-only lifecycle refinement from V100.3.10.3.

## Certified improvement

- Synchronizes the existing Service `Check down` stage to the Floor's existing CHECK table state.
- Keeps the CHECK state visible in regular and full-screen Floor modes.
- Returns the visual label to SEATED if Service moves out of CHECK.
- Clears CHECK, guest ownership, service-stage ownership, and the seated timestamp when completed service moves a table to CLEANING.
- Clears residual CHECK/service-stage state when staff manually returns a cleaned table to OPEN.

## Preserved

- Human-owned CLEANING → OPEN transition.
- Existing seating eligibility and confirmation.
- Regular and full-screen section switching.
- Reserved-table controls and fullscreen status dialogs.
- Guest-freeze protection and focused workspace behavior.
