# BLUE CURRENT V51.10.0 — RESTAURANT DAY LIFECYCLE

V51.06–V51.10 turns Blue Current's existing restaurant capabilities into one ordered restaurant-day rehearsal and certification workflow.

## Lifecycle

1. OPENING
2. PRE_SHIFT
3. RESERVATIONS
4. SEATING
5. ACTIVE_SERVICE
6. KITCHEN_COORDINATION
7. GUEST_RECOVERY
8. CLOSING

The sequence is enforced.

A later stage cannot be completed before the prior stage.

## Human checkpoint evidence

Each lifecycle checkpoint requires human-recorded evidence.

Blue Current does not infer that a stage is complete because modules exist or because data looks plausible.

Each checkpoint records:

- stage
- actor
- timestamp
- evidence
- prerequisite snapshot
- override state
- override reason when used
- `operationalMutationPerformed: false`

## Operational prerequisites

Each stage reuses the existing authoritative restaurant model.

### Opening
- restaurant record
- tables and sections
- authorized operating access

### Pre-shift
- active workforce / labor path
- sections available
- restaurant present in the V51 pilot baseline

### Reservations
- reservation data or reservation connector
- floor available to receive reservations

### Seating
- floor/table model
- reservation context

### Active service
- dining room
- active workforce
- sections

### Kitchen coordination
- kitchen stations or kitchen connector
- restaurant service context

### Guest recovery
- reservation/guest context
- authorized operator access

### Closing
- restaurant operating context
- workforce context

## Rehearsal before pilot GO

V51 intentionally allows `PILOT_READINESS_REHEARSAL` before the V51.05 baseline reaches GO.

That lets the team exercise and expose broken workflows while the restaurant is still being prepared.

A baseline-ready location uses:

`PILOT_OPERATING_REHEARSAL`

A location with open pilot gates uses:

`PILOT_READINESS_REHEARSAL`

Neither mode is a production go-live authorization.

## Open prerequisites

If a stage has missing prerequisites, it remains `BLOCKED`.

A human can continue an intentional rehearsal only by entering a documented override reason.

The missing prerequisite remains visible in the captured checkpoint snapshot.
