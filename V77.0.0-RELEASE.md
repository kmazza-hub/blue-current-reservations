# V77.0.0 — Manager Action Queue & Accountability Loop

V77 turns ranked Command priorities into human-owned operating work.

A manager can now acknowledge the current #1 verified priority and create an accountable action. The action preserves the priority evidence, score, recommendation, data mode, and confidence at the moment it was acknowledged.

Action lifecycle:
- acknowledged
- assigned
- in_progress
- resolved or dismissed

Each action carries an owner, timeline, outcome, audit history, and realtime update. Duplicate open actions for the same location/domain/title are suppressed.

Safety boundaries:
- a priority must still be active in the current Command picture before it can become an action
- location access is enforced
- closed actions cannot be restarted
- Blue Current never auto-acknowledges, auto-assigns, auto-starts, or auto-resolves work
- manager/operator confirmation is required for every state change
