# V69.50.0 — Authentication, Session Lifecycle & Organization Isolation Hardening

V69.50 closes the next production security layer.

## Session lifecycle
- absolute session lifetime
- idle-session timeout
- periodic last-seen/idle-expiry refresh
- explicit revocation state instead of relying only on deletion
- logout revocation and security audit
- logout-all across a user's active sessions
- maximum concurrent active sessions per user
- startup cleanup of expired/old revoked sessions

## Login abuse escalation
Blue Current now persists per-email failed-login security state.

After the configured threshold inside the configured time window:
- a temporary login lock is applied
- subsequent attempts remain generic to avoid account enumeration
- the event is written to the security audit trail

## Organization isolation
- organization switching requires a live membership
- denied switches are security-audited
- role/location scope is resolved from the current membership
- an administrator can revoke sessions only for a user who belongs to the administrator's current organization

## Diagnostics
Admin-only:
`GET /api/system/auth-security`

Self-service:
`POST /api/auth/logout-all`

Admin:
`POST /api/system/auth-security/revoke-user`
