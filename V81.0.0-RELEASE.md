# V81.0.0 — Live Pilot Command & Shift Control

V81 creates the live-pilot shift lifecycle.

Phases:
- PRE_SHIFT
- LIVE
- CLOSED

A live shift requires a current human GO or accepted GO_WITH_CONDITIONS certification.
Only one active pilot shift may exist per location.

The live command snapshot continuously exposes:
- certification decision
- runtime safety state
- provider authority state
- provider continuity
- open and critical incidents
- local fallback availability
- external write availability
- recommended operator action

Shift start and close are explicit human actions.
Closeout records service outcome, operator notes, guest impact, incident state,
runtime state, authority state, and follow-up requirement.

Autonomous production changes remain disabled.
