# Blue Current V100.3.40

## iPad Pilot Readiness

This forward-only wave closes the verified installability gap found during the physical-device readiness inspection. Blue Current now supplies explicit Safari and PWA icons while preserving the existing viewport, safe-area, touch, reconnect, resume, and focused-workspace foundations.

### Implementation

- Adds a dedicated 180×180 Apple touch icon for iPad Home Screen installation.
- Adds required 192×192 and 512×512 PNG icons to the web app manifest.
- Adds a stable manifest application identity.
- Aligns the installed app theme color with Blue Current's browser chrome.
- Versions the manifest and touch-icon references so devices do not retain stale metadata.

### Certification

The V100.3.40 maintenance gate verifies install metadata and icon bytes, exact icon dimensions, accessible zoom, 44px touch targets, safe-area protection, keyboard-visible viewport sizing, momentum scrolling, reconnect/resume safeguards, and lazy-load availability for Kitchen and Staff.

### Physical acceptance boundary

Automated validation cannot certify Safari rendering on Keith's physical iPads. The included operator runbook is the final human acceptance gate and records the exact frontline sequence to execute on the intended device and network.

### Data safety and rollback

No database file is included or changed. Rollback consists of reverting the V100.3.40 manifest and HTML metadata changes and removing the three V100.3.40 PNG assets and certification documents.
