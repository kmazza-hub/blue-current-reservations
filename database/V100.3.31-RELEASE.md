# Blue Current V100.3.31 — Frontline Seating Location Integrity

This wave certifies and strengthens the restaurant boundary across the host seating lifecycle.

- Floor and reservation-operation reads require an explicit restaurant instead of silently loading Marina.
- New waitlist and reservation records require explicit restaurant identity.
- Waitlist seating resolves both the waiting party and selected table before mutation.
- Reservation seating verifies the reservation and table belong to the same organization and restaurant.
- Existing transactional service guards remain in place for status, table availability, capacity, and matched floor truth.
- No database or restaurant records are included.
