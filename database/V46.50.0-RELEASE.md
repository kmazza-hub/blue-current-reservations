## V46.49 — Guarded Authoritative Apply

Because ZIP overlays cannot delete files safely, V46.50 is delivered with a guarded Node apply script.

The script:
1. verifies exact V46.45 baseline hashes
2. creates a backup outside the repository
3. copies only V46.50 payload files
4. deletes only the two authorized module files
5. verifies post-retirement hashes
6. runs `npm run check`
7. runs `test-authoritative-retirement-v46.50.js`
8. automatically restores the backup if application or validation fails

The script refuses to proceed on baseline drift.

## Safety

V46.50 performs one narrowly scoped, previously rehearsed code retirement.

It does NOT:
- delete database data
- enable autonomous live restaurant mutation
- bulk-retire other candidates
- create a generic unaudited deletion endpoint

Future permanent retirements must independently pass the same evidence, rehearsal, authorization, apply, and rollback gates.
