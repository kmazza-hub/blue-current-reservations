# BLUE CURRENT V65.0.0 — EMPTY STATES, ERROR RECOVERY & FIRST-TIME CLARITY

Makes quiet, blank, loading, unavailable, and disconnected states explain themselves.

- Converts common primary-workspace empty states into understandable operational states.
- Distinguishes healthy zero states from failures.
- Dynamically decorates re-rendered loading/empty messages.
- Adds a persistent recovery banner only when the browser actually goes offline.
- Adds Retry now using the existing connection-check workflow.
- Adds one concise first-use orientation: Start with Live; use Quick Jobs for a known task.
- Adds `bluecurrent:recovery-needed` as the standard module recovery-feedback event.
- Does not add a blocking tutorial or remove any workflow.
