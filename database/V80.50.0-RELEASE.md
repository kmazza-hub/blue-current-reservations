# V80.50.0 — Pilot Incident Resolution & Recovery Certification

Closes the service-night incident loop.

Incident lifecycle:
OPEN -> INVESTIGATING -> RESOLVED

Recovery certification requires:
- documented root cause
- documented corrective action
- documented recovery evidence
- stable provider continuity
- trusted provider state
- recovery checks passing
- no other unresolved critical incident

Resolving an incident does not restore provider authority.
Emergency local mode can be cleared only after critical incidents are recovery-certified.
Provider recutover remains a separate explicit human action.
