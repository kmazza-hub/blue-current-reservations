# V100.3.17 — Frontline Location Authority

Forward-only pilot-configuration foundation from V100.3.16.

## Certified improvements

- Gives frontline Staff, Scheduling, Time Clock, and Service exception sync one shared location authority.
- Accepts a pilot location through `?location=LOCATION_ID` only when that location is authorized for the signed-in user.
- Persists the authorized selection for repeat iPad entry.
- Rejects unauthorized location selection and falls back safely to Marina during development.

## Preserved

- Server authorization remains authoritative for every API request.
- Existing Chefs development behavior remains on `loc_marina` when no pilot location is selected.
- Floor, Host, Service, Kitchen, Staff, and Time Clock lifecycles are otherwise unchanged.
- No restaurant configuration, membership, or database record is automatically modified.
