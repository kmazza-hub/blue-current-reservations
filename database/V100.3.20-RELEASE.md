# V100.3.20 — Command Location Continuity

Operator-safety hardening from V100.3.19.

## Certified improvements

- Binds Command's visible location selector to the same authorized authority used by Reservations, Floor, Service, Kitchen, Staff, Scheduling, Time Clock, Manager, and Inventory.
- Removes unauthorized restaurant choices from the Command selector.
- Rejects unauthorized changes and restores the current restaurant without silently switching data.
- Performs a clean page transition after a valid location change so every workspace starts on the same restaurant.
- Shows the active restaurant in the persistent navigation rail.

## Preserved

- Existing Command operating-picture requests remain unchanged.
- Server-side authorization remains authoritative.
- No restaurant state is mutated by choosing a working location.
- No polling or broad document observer is introduced.
