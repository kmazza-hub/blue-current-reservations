# BLUE CURRENT V46.20.0 — OPERATOR CONSOLIDATION SCORECARD

## Release scope

V46.16–V46.20 converts the fine-comb evidence model into a measurable operator-consolidation scorecard.

This release does not delete modules automatically.

### V46.16 — Navigation Duplication Measurement
Measures duplicate navigation entry points within each navigation surface.

Responsive desktop/mobile mirrors are not treated as duplicates merely because they point to the same destination.

On the current authoritative baseline, the desktop navigation contains 5 excess duplicate entries:
- Autonomous appears 3 times
- Guests appears 2 times
- AI Brain appears 2 times
- Executive appears 2 times

The mobile navigation has no internal duplicate entry points.

### V46.17 — Primary Workflow Coverage
Measures whether role-default navigation covers the six required operator stages:

1. Reservations
2. Floor
3. Kitchen
4. Staffing
5. Guest Recovery
6. Profit

Manager role coverage is expected to remain 100%.

### V46.18 — Handoff + Clicks-to-Action Score
Adds:
- unresolved/attention handoff count
- clear-handoff percentage
- operator-use evidence count
- role-specific usage
- clicks-to-action proxy from instrumented use events

The clicks-to-action metric is explicitly labeled as an instrumentation proxy rather than a production analytics claim.

### V46.19 — Evidence-Backed Deprecation Shortlist
Deprecation candidates can now be classified as:
- `eligible-for-deprecation-review`
- `retain-observed-use`
- `blocked-until-primary-coverage`

Eligibility requires:
- zero observed use for the candidate
- 100% manager primary-workflow coverage

Even an eligible candidate is review-only.

### V46.20 — Consolidation Scorecard
Adds a weighted score combining:
- navigation duplication
- primary workflow coverage
- handoff health
- operator-use evidence

The scorecard returns:
- numeric score
- A–F grade
- duplicate-navigation groups
- workflow coverage
- handoff health
- usage by role
- clicks-to-action proxy
- evidence-backed deprecation shortlist

Policy:

`evidence-backed-review-no-automatic-deletion`
