# Blue Current V100.3.30 — Frontline Labor Record Authorization

This wave protects scheduling, workforce, and time-clock records at the authenticated API boundary.

- Scheduling and workforce reads require an explicit restaurant.
- Shift edits, deletions, and Smart Fill authorize the stored shift location.
- Employee edits, availability, PTO requests, and PTO decisions authorize the employee's restaurant.
- Clock actions authorize the employee; clock-in also requires the submitted restaurant to match the employee record.
- Timecard corrections authorize the stored timecard location.
- Employee ownership is verified before an update is applied.
- No database or restaurant records are included.
