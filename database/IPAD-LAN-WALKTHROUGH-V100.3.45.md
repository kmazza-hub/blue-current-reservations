# iPad LAN Walkthrough

1. Connect the Windows computer and iPad to the same private Wi-Fi network.
2. Run `npm run pilot:lan` in PowerShell.
3. Keep PowerShell open and enter one printed `http://...:8787` address in iPad Safari.
4. Sign in and execute launch, reservation, arrival, waitlist, seating, Floor, Service, Kitchen, Staff, and interruption/recovery.
5. Record each outcome as CLEAR, FRICTION, or BLOCKED using the V100.3.44 evidence requirements.
6. Press Ctrl+C in PowerShell only after the walkthrough is complete.

If Windows asks about firewall access, allow Node.js only on the private network. Do not enable public-network access and do not use this LAN launcher as hosted pilot infrastructure.
