# Blue Current V44.7.0 — Persistent Agent Runtime & Recovery

## Release scope
V44.7.0 advances Operation V from the V44.3 AIP runtime foundation into a durable server-backed agent lifecycle without enabling automatic live restaurant execution.

## V44.4 — Persistent Agent Runtime
- Adds server-persisted AIP agent runs created from compiled automation drafts.
- Persists owner, agent type, intent, capability references, plan length, lifecycle history, and governance state.
- Approval-gated drafts enter `approval-pending` and are explicitly blocked from starting.
- All runs use `governed-dry-run`; `liveStateChanged` remains false.

## V44.5 — Shared Execution Context
- Adds a server-generated execution-context view for a selected persistent run.
- Reuses one database snapshot to assemble draft steps, sandbox evidence, capability references, lifecycle state, and governance boundaries.
- Makes `liveExecutionAllowed: false` explicit in runtime context.

## V44.6 — Runtime Checkpoints & Recovery
- Adds durable runtime checkpoints.
- Adds governed lifecycle transitions: start, checkpoint, pause, resume, recover, complete, cancel.
- Persists transition history and emits audit/realtime records.
- Recovery restores the run's logical dry-run step position from the latest persisted checkpoint; it does not replay or mutate live restaurant state.

## V44.7 — AIP Runtime Readiness II
Expands the V44 readiness gate to verify:
- V43 closure
- capability registry
- automation compiler
- execution sandbox
- persistent agent runtime
- shared execution context
- checkpoint persistence
- pause/resume/recovery evidence
- no automatic live execution
