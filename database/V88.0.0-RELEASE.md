# V88.0.0 — Restaurant Configuration Foundation

V88 begins Phase C by making restaurant-specific operating configuration a governed
data contract rather than a code change.

The configuration foundation covers location identity, timezone, service periods,
dining areas, tables, operating roles, operating targets, integration assignments,
and pilot controls.

Configuration writes are admin-gated and audited. Pilot configuration cannot enable
provider write-back or autonomous production changes.

Next gate: Pilot Location Configuration Certification.
