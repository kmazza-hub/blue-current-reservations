# Blue Current V100.3.51 — Controlled Demonstration Mode

This wave adds an explicit fictional sales-demonstration path without changing or certifying a real restaurant configuration.

## Open the demonstration

After signing in, open:

`http://localhost:8787/?demoSetup=1`

For an iPad using the active Cloudflare tunnel, append `/?demoSetup=1` to that tunnel URL.

## Safety boundary

- Harbor & Hearth Tavern is fictional.
- The experience uses the existing seeded development environment.
- No live restaurant system or POS write-back is enabled.
- Demo navigation does not call pilot-evidence endpoints.
- Completing the demonstration cannot satisfy pilot certification.
