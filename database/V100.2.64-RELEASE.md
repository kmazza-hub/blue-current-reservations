# V100.2.64 — Staffing Truth Foundation

Begins the Staffing MVP from authoritative Time & Attendance data.

- Shows who is clocked in now.
- Shows break state, worked hours, overtime risk, and missed-punch exceptions.
- Missed punches become First Priority, then overtime exposure.
- Links directly to the existing Time Clock workflow for action.
- Does not calculate or display synthetic demand, scheduled coverage, or callout risk in the primary operator view.
- Does not modify Host/Floor, Kitchen, Time Clock, Workforce Intelligence, or Cloud API runtime files.
