# BLUE CURRENT V45.15.0 — GOVERNED INTERVENTION AUTHORIZATION

## Release scope

V45.11–V45.15 advances Autonomous Operations from intervention rehearsal into scoped authorization and non-executable command drafting.

This release still does not introduce a live execution boundary.

### V45.11 — Approval Packet Builder
A conflict-free rehearsal can now be converted into a policy-aware approval packet.

Each packet retains:
- rehearsal ID
- exact proposal scope
- required approval role
- evidence/policy SHA-256 digest
- approval scope
- expiration
- revocability
- live-state isolation markers

Approval packet scope is explicitly:

`command-draft-only`

### V45.12 — Evidence / State Revalidation
Before approval and before command drafting, Blue Current revalidates:
- packet expiry
- rehearsal status
- blocking conflicts
- proposal-set completeness
- evidence/policy digest
- proposal safety boundary
- authorization scope

A stale or changed packet cannot progress without a new approval cycle.

### V45.13 — Scoped Approval, Expiry, and Role Enforcement
Approvals:
- expire after 15 minutes
- require a role at or above the packet's required approval role
- remain limited to command drafting
- never grant live execution

Current role hierarchy:
Manager → General Manager → Regional Operator → Executive

### V45.14 — Revocation
Approved authorization can be revoked.

Revocation is persistent, auditable, realtime-published, and immediately blocks creation of additional command drafts.

### V45.15 — Non-Executable Command Drafting + Authorization Readiness
Approved and freshly revalidated packets can produce command drafts.

Every command draft has:
- `status: draft-only`
- `executionEndpoint: null`
- `requiresSeparateExecutionCertification: true`
- `liveExecutionAllowed: false`
- `liveStateChanged: false`

Authorization readiness certifies:
- approval packet construction
- scoped expiry
- evidence/state revalidation
- role boundaries
- revocation architecture
- command/execution separation
- authorization scope
- live-state isolation

## Safety boundary
This release deliberately has no command execution endpoint.

Approval grants permission only to produce a command draft. Draft commands are inert architecture records and cannot mutate restaurant operations.

## Operation V position
The next V45 milestone should define the separately certified execution boundary: action adapters, command validation, preflight checks, idempotency, rollback/compensation contracts, emergency stop, bounded domain allowlists, and shadow/canary execution.
