# V86.75.0 — Connector Observability & Integration Health Command

Consolidates V86 integration readiness, sync reliability, checkpoint recovery, and
data reconciliation into one read-only integration health command.

The operator-facing model answers whether connected data is TRUSTED, USE_WITH_CAUTION,
or DO_NOT_TRUST and exposes connector-specific recovery actions without granting
automatic write-back or operational authority.
