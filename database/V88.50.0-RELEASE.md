# V88.50.0 — Pilot Data & Workflow Binding

V88.50 binds a certified restaurant configuration to the operational domains Blue Current
will exercise during pilot: guests, reservations, tables, live service, team, kitchen,
and POS/revenue context.

Table/service context comes from the certified restaurant configuration. External provider
sources remain read-only during pilot. Any subsequent restaurant configuration change
invalidates the binding and requires recertification/rebinding.
