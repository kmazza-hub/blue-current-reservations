# V100.2.40 — Reserved Modal Portal + Reservation-to-Floor Handoff

## Fixed
- Reserved-table cards no longer sit underneath floor tables. The card is now mounted at the document level, centered, and layered above every floor/table stacking context.
- **Mark arrived** from the full Reservations detail view now moves that reservation into the live Floor seating queue.
- **Add to waitlist** from the same detail view now performs the same queue handoff instead of only closing the dialog.
- Reservation-to-floor handoff reuses the existing V100.2.17 priority-queue API when available and includes a deduplicated fallback.
- After handoff, the operator lands on **Floor > Waitlist** so the guest is immediately actionable.

## Preserved
- V100.2.39 collision-safe floor positions
- V100.2.38 centered neutral-table details
- table-fit behavior
- table lifecycle states
- room zoning
- wait-time logic
- existing seating flow
