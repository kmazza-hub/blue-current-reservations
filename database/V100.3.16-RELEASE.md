# V100.3.16 — Live Service Window

Forward-only Service/Kitchen credibility refinement from V100.3.15.

## Certified improvements

- Treats browser-cached Service handoffs as live operating state rather than permanent history.
- Removes parties untouched for more than one extended 18-hour restaurant operating window.
- Publishes a scoped prune event so Kitchen immediately removes matching orphaned Ready state.
- Prevents Service and Kitchen from reopening with prior-day parties and enormous stage ages.

## Preserved

- Current seated and recently updated parties remain active.
- Host seating remains the authoritative Service intake.
- Service completion still moves the table to Cleaning and requires a human to mark it Open.
- Reservations, checks, table state, guest history, and backend records are not changed.
