# BLUE CURRENT V45.5.0 — AUTONOMOUS OPERATIONS FOUNDATION

## Release scope

V45 begins Blue Current Autonomous Operations by connecting the governed V44 AI runtime to restaurant operating evidence. This release intentionally stops before live execution.

### V45.1 — Operational Observation Frame
- Normalizes the existing Autonomous Operations snapshot into an evidence-backed operating frame.
- Retains location-level occupancy, waitlist, ticket time, ready tickets, staffing, health, revenue trend, forecast, labor, food cost, and margin evidence.
- Uses one existing snapshot as the decision-cycle source rather than creating a new nested API fan-out.

### V45.2 — Cross-Domain Anomaly Detection
Detects governed operating anomalies in:
- kitchen throughput
- reservation pacing
- staffing coverage
- guest recovery
- revenue opportunity

Each anomaly retains its evidence, severity, score, location, reason, and detection time.

### V45.3 — Agent-Scoped Recommendation Planner
Maps detected anomalies to specialized V44-style agents:
- Kitchen Flow Advisor
- Operations Optimizer
- Staffing Advisor
- Guest Experience Advisor
- Revenue Planner

Every recommendation:
- is evidence-backed
- requires approval
- requires simulation
- is governed-dry-run only
- cannot mutate live restaurant state

### V45.4 — Intervention Simulator
Creates a modeled intervention result for every recommendation before execution.
Simulation outputs are explicitly `simulation-only`.
No reservations, staff schedules, floor state, kitchen tickets, guest records, offers, or messages are changed.

### V45.5 — Autonomous Assistance Readiness
Adds a readiness gate covering:
- operational observation
- anomaly detection
- agent-scoped recommendations
- simulation-before-execution
- evidence retention
- approval requirements
- live-state isolation

## UI

- recommendation/simulation counts

- V45 readiness status

## Safety boundary
V45.5.0 does not call the legacy autonomous auto-execution path.

The new V45 path is restricted to:

`Observation → Anomaly Detection → Recommendation → Simulation`

All V45 recommendations require approval and all V45 simulation state carries:
- `liveExecutionAllowed: false`
- `liveStateChanged: false`
