# V83.0.0 — Multi-Location Operating Governance & Portfolio Health

Introduces an executive portfolio view across authorized restaurant locations.

The portfolio aggregates:
- location operating health
- rollout / stabilization state
- open and critical incident concentration
- provider continuity degradation
- support burden
- operating consistency
- prioritized executive attention

This layer is advisory and observational. Each location retains independent
authority boundaries. Portfolio health never causes automatic cross-location
actions, rollout expansion, provider authority expansion, or autonomous
production changes.
