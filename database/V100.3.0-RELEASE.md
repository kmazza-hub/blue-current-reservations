# V100.3.0 — Service → Manager Exception Visibility Integrity

Connects real Service recovery exceptions to the existing live Manager Actions ledger.

When a known Service stage exceeds its recovery threshold, Blue Current sends the current exception snapshot to one authenticated, location-scoped server route. The server creates one deterministic, high-priority Manager Action per party and stage, refreshes its known context without duplicating it, and automatically resolves it only when that underlying Service exception disappears.

Manager completion remains human-owned and is not reopened by repeat synchronization. Operations Feed entries are written only when an exception opens or clears. Hashed record identity keeps guest names out of action IDs.

This wave adds no second queue, manager dashboard, Service store, inferred root cause, or automatic Service milestone advancement.
