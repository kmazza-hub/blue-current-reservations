# V73.50.0 — Live-Shift Failure Paths, Conflict Handling & Recovery Certification

V73.50 certifies restaurant workflows under failure and retry pressure.

- duplicate seating and table conflicts are rejected
- repeated service completion is safe
- interrupted transactions roll back without partial restaurant state
- kitchen tickets/items enforce legal state transitions
- duplicate API operations use idempotency records
- stale client writes are rejected by resource-version checks
- restart recovery uses durable mutation/idempotency evidence
- ambiguous restart mutations remain reconcile-required
- no automatic repair is performed

New endpoint:
`GET /api/system/live-shift-failure-certification`
