# V100.3.10.1 — Guest Freeze Repair

## Scope
Emergency forward-only repair for a regression introduced by V100.3.10 floor interaction clarity.

## Root cause
The V100.3.10 floor clarity module attached a MutationObserver to the entire document body and listened to class/hidden mutations across the full application. Guest workspace rendering produces many of those mutations, causing a mutation-processing storm and page freeze.

## Repair
- Removed the global body subtree observer.
- Observe only Floor Focus entry/exit on the root html class.
- Attach a narrow observer only to the active full-screen floor map while Floor Focus is open.
- Disconnect that floor observer immediately when Floor Focus exits.
- Preserve V100.3.10 table interaction and floor presentation behavior.
- Bump the script cache query to 100.3.10.1.

## No-change boundaries
No changes to guest search data, reservations, seating semantics, service lifecycle, kitchen, staffing, auth, backend, or persistence.
