# BLUE CURRENT V49.20.0 — GO-LIVE COMMAND

V49.16–V49.20 adds the final human-controlled command layer before and after production cutover.

## Final pre-cutover checks

Each location with a prepared deployment package is re-evaluated for:

1. Deployment package prepared.
2. Human go-live authorization still present.
3. Technical readiness complete or explicitly overridden at authorization.
4. Deployment owner assigned.
5. Rollback owner assigned.
6. Launch window defined.
7. Production cutover has not already been recorded successful.

Open final checks require a documented executive override before manual cutover can be authorized.

## Manual cutover execution authorization

Adds:

`POST /api/go-live-command/locations/:locationId/authorize-execution`

Authorization records:

- deployment package
- location / rollout wave
- deployment operator
- rollback operator
- launch window
- authenticated authorizer
- final pre-cutover snapshot
- override status and reason
- note

The resulting state is:

- `status: AUTHORIZED_FOR_MANUAL_CUTOVER`
- `deploymentExecutionState: AUTHORIZED_NOT_EXECUTED`
- `productionCutoverState: NOT_PERFORMED`

Authorization does not run commands, deploy infrastructure, modify connectors, or perform production cutover.

## Human-recorded cutover result

Adds:

`POST /api/go-live-command/locations/:locationId/record-result`

Supported results:

- `CUTOVER_SUCCEEDED`
- `CUTOVER_FAILED`
- `ROLLED_BACK`

Results can only be recorded after manual execution authorization.

A successful cutover result requires every post-cutover health check to be explicitly confirmed:

- API healthy
- authentication healthy
- reservation integrity
- floor integrity
- kitchen integrity
- workforce integrity

A failed result requires a launch incident description.

A rollback requires a rollback operator.

Each result explicitly records:

- `resultSource: HUMAN_RECORDED`
- `systemExecutionClaim: false`

Blue Current records what a human deployment operator reports. It does not claim to have executed the deployment.

## Launch incident state
