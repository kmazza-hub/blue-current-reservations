# V77.50.0 — Outcome Verification & Closed-Loop Learning

V77.50 closes the loop between a ranked Command priority, the manager action taken, and the operating state observed after resolution.

## Baseline capture
When a priority is acknowledged, Blue Current stores a domain-specific operating baseline.

Examples:
- Kitchen: active ticket + food-ready pressure index
- Guests: quoted wait minutes
- Service: occupancy + wait pressure
- Inventory: low-stock item count

## Resolution verification
When a manager resolves an action, Blue Current reads the current operating picture and compares it with the baseline.

Outcome classifications:
- IMPROVED
- UNCHANGED
- WORSENED
- UNVERIFIED

Blue Current records the metric, before value, after value, delta, and context.

## Closed-loop learning
Verified outcomes are stored in `commandOutcomeLearning` and surfaced through:

`GET /api/command/outcomes`

The Command UI now shows recent verified outcomes and counts.

## Critical limitation
This is observational learning, not causal inference.

Blue Current does NOT claim:
- that the manager action caused the improvement
- that a recommendation is proven optimal
- that the same intervention should be executed automatically next time

All learning records remain ineligible for autonomous execution.
