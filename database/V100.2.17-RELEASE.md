# V100.2.17 — Arrival Check-In + Priority Seating Queue

Blue Current Host Stand now uses a simpler physical-presence model:

- **Arrivals** contains expected reservations that have not checked in.
- Every expected reservation gets a prominent **Mark arrived** action.
- Marking a reservation arrived removes it from Arrivals and places it in the ready-to-seat queue.
- Ready-to-seat reservations use the same guided **Seat → choose table → confirm** flow as walk-ins.
- Birthday, anniversary, allergy, accessibility, high-chair, VIP, and other special-context guests receive stronger visual and queue priority.
- Reservation vs. walk-in source remains visible.
- The duplicate/blank active-party banner introduced by overlapping guided flows is suppressed.
- Arrivals and ready-to-seat counts are reconciled after each transition.

No authentication, server, database, RBAC, Command shell, Service, or Kitchen logic is changed.
