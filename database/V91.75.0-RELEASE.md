# V91.75.0 — Shift Start & Handoff Operator Flow

Command now gives managers a compact shift-control bridge that answers three questions:
what state am I inheriting, what matters first, and what ownership is still open.

The same surface toggles into Handoff mode so the outgoing manager can see the operating
state, top live priority, and unresolved manager actions the next manager inherits.

This wave deliberately consolidates existing Command prioritization and manager-action data.
It does not create a second handoff ledger or automatic ownership system.
