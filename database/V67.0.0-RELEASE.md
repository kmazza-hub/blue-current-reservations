# BLUE CURRENT V67.0.0 — MOBILE COLOR, SPACING & TOUCH LAYOUT

Focused mobile usability wave.

This pass keeps the desktop system intact and corrects the narrow-screen experience:

- brighter light surfaces and stronger text contrast
- bright white / light-blue content on dark Live and Service cards
- tighter vertical rhythm and less dead space
- consistent 10–14px mobile card spacing
- responsive KPI grids
- single-column operational layouts
- compact two-column Host navigation
- horizontally scrollable wide tables instead of unreadable compression
- full-width readable forms and dialogs
- 44–46px minimum mobile controls
- compact operator utility controls
- smaller three-column Rush Dock
- mobile-safe toast and recovery placement
- reduced header/navigation density

No workflow, API, or desktop capability is removed.
