# V78.50.2 — Light Surface Typography Contract

This wave standardizes typography contrast across light-background Blue Current surfaces.

## Fixed
- Inventory Intelligence headline and supporting copy now use dark high-contrast text on the light canvas.
- Light-background product sections receive an explicit dark typography contract.
- White/light cards inside dark workspaces receive dark text.
- Dark operational cards nested inside light screens keep white/light typography.
- Light-surface form fields no longer inherit white text.
- Mobile keeps the same contrast rules.

## Covered light surfaces
- Operator
- Host Stand
- Guest Intelligence
- Hospitality Analytics
- Predictive Operations
- Intelligence Network
- Inventory Intelligence
- light Portfolio focus cards
- light Predictive cards
- light Guest cards

This is a visual/contrast wave only. No operational API behavior is changed.
