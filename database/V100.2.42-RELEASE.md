# V100.2.42 Release

## Zero-Overlap Restaurant Floor Spacing

- Replaces inherited `--x/--y` placement with direct `left/top` coordinates for the production sample floor.
- Main floor uses four fixed columns by four fixed rows.
- Waterfront uses four fixed columns by three fixed rows.
- Private dining uses four fixed columns by two fixed rows.
- Selected-table scale is reduced to avoid visual collision.
- Six- and eight-top widths remain bounded.
- No reservation, waitlist, seating, lifecycle, or persistence behavior changes.
