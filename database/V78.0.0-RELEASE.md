# V78.0.0 — Intervention Effectiveness & Playbook Intelligence

V78 turns V77.50's closed-loop outcome records into evidence-backed operating playbooks.

## Similar-condition grouping
Outcome records are grouped by:
- operational domain
- verification metric
- intervention/recommendation
- baseline intensity band (low / moderate / high)

This prevents Blue Current from treating a mild service condition as equivalent to a severe one.

## Intervention effectiveness
For each repeated intervention pattern Blue Current calculates:
- sample size
- verified samples
- improved / unchanged / worsened counts
- improvement rate
- worsened rate
- average observed metric delta
- number of locations represented
- confidence level

## Evidence thresholds
Guidance is classified:
- EVIDENCE_BACKED
- PROMISING
- EARLY_SIGNAL
- INSUFFICIENT_EVIDENCE

Strong guidance requires at least 8 observed outcomes and a >=70% improvement association.

## Command UI
The Intelligence panel now includes Playbook Intelligence showing:
- recommendation/intervention
- evidence status
- sample size
- improvement rate
- confidence
- explicit observational-only caution

New endpoint:
`GET /api/command/playbooks`

## Safety boundary
This is observational association, not causal inference.
Blue Current does not claim the intervention caused the improvement and does not approve any playbook for autonomous execution.
Manager review remains required.
