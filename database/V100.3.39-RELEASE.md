# Blue Current V100.3.39

## Frontline Failure and Rush Stress Certification

This forward-only certification wave proves that the Chefs International frontline loop remains truthful when operators act simultaneously, retry actions, work from stale tablet state, encounter invalid lifecycle requests, lose a session, and restart the server.

### Certified behavior

- Concurrent reservation and waitlist intake retains every unique guest record.
- Two operators competing for one table produce exactly one seating winner.
- The rejected contender cannot overwrite the winning table assignment.
- Repeating the winning action with the same idempotency key safely replays its original result.
- Stale `If-Match` writes return `412 VERSION_CONFLICT` and preserve current state.
- Invalid reservation lifecycle transitions return `409 INVALID_RESERVATION_TRANSITION`.
- Expired sessions are denied after restart and a fresh login restores access.
- Rush data and the winning collision outcome survive server restart.

### Data safety

The certification creates a unique temporary database from the seed fixture, starts the application on an isolated local port, and removes the temporary database after completion. It does not read from or write to the live Blue Current database.

### Scope

This wave adds certification coverage only. It does not add dashboards, analytics, integrations, or speculative product behavior.
