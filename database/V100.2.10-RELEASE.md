# V100.2.10 — Table Assignment & Seating Lifecycle

Closes the Host Stand gap where a table could remain stuck at `Assigned to Anthony` without showing a guest location or completing the assignment-to-seating transition.

## Behavior
- Assignment produces an actionable `Seat Anthony at Table 14` next step.
- Seating changes the table from Reserved to Seated/Occupied.
- Anthony Russo is labeled `Seated · Table 14` in Arrivals.
- Selected-table detail changes from Next guest to Current guest.
- The stale assignment button is removed after seating.
- Host recommendation reports the completed guest/table relationship.

## Guardrails
No authentication, Command shell, server API, database, RBAC, reservation creation, generic waitlist Seat behavior, or persistence changes.
