## Certification states

The certification endpoint can return:

- `V49-CERTIFIED-LIVE`
  - all architecture contracts pass
  - current rollout reached a human STABLE declaration across launched locations

- `V49-ARCHITECTURE-CERTIFIED`
  - all architecture contracts pass
  - the real rollout has not yet completed the full live chain

- `V49-CERTIFICATION-FAILED`
  - one or more human-control architecture contracts failed
