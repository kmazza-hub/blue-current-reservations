# Blue Current V35.5.0 — Pilot-Ready Performance Platform

## Business value
V35.5.0 consolidates the complete performance loop into a governed release gate. Operators can verify that Restaurant Performance, measured outcomes, executive briefings, portfolio intelligence, calibration, approvals, and runtime integration are all functioning before a restaurant pilot begins.

## Engineering
- Adds `pilotReleaseEngine.js` and `pilotReleaseCenter.js`.
- Audits V35 factories, published AppState snapshots, DOM contracts, duplicate script loads, approval gates, calibration, measured evidence, and integration health.
- Produces a downloadable JSON release manifest.
- Persists readiness history in AppState and publishes `pilot-release:updated`.
- Adds a high-contrast Pilot Control Center.

## Governance
A high readiness score does not remove human approval. Modeled revenue remains an operational estimate, and weak evidence domains remain visible as watch conditions.
