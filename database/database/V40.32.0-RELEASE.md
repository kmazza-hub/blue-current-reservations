# Blue Current V40.32.0 — AIP Learning Governance

This release closes the loop between pilot evidence and governed AI improvement.

## V40.30 — Improvement Backlog
Converts learning-loop actions, low-rated feedback, watch observations, and failed evaluations into an owned work queue with priority and status tracking.

## V40.31 — Prompt Experiment Lab
Compares control and variant prompts in an isolated deterministic scoring harness. Experiments produce evidence only and never deploy a prompt automatically.

## V40.32 — Learning Release Gate
Requires learning evidence, owned improvement work, closure of high-priority blockers, prompt experiment evidence, and safety-test evidence before a governed promotion can be approved.

No module in this release automatically rewrites prompts, changes agent policy, deploys models, or executes operational actions.
