# Blue Current V34.0.0 — CC-001

## User story
As a restaurant manager, I want one operating brief at the top of the application so I can understand what happened, what is happening, and what needs action before service.

## Added
- Restaurant Command Center navigation entry
- Dynamic greeting date and location line
- Restaurant readiness score and status signals
- Local weather pilot card
- Same-day-last-year and last-week comparisons
- Today's reservations, staffing, PTO, and projected labor snapshot
- Needs-attention list
- Previous-shift handoff summary and acknowledgment
- AI operating recommendation card
- Interactive manager action list
- Responsive desktop, tablet, and mobile layouts

## Data status
Weather, historical sales, forecasts, and shift information are pilot data in this story. This establishes the complete UI and interaction contract before API integrations are introduced.
