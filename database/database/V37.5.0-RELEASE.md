# Blue Current V37.5.0 — Progressive Startup Control

This accelerated release contains three connected startup-performance waves.

## V37.3 Progressive Feature Packs
Loads Operations, Intelligence, Enterprise, or Integrations as deliberate startup profiles instead of starting the entire platform.

## V37.4 Startup Performance Monitor
Measures boot time, loaded scripts, long tasks, and a startup performance score against explicit budgets.

## V37.5 Boot Recovery Guard
Adds a 12-second watchdog, last-good startup profile, failure history, focused-mode recovery, and safer startup error handling.

All existing feature files remain available. Full platform mode is still available with `?full=1`.
