# Blue Current V39.6.1 — Guided Shift Render Hotfix

## Fixed

- Corrected the `guidedShiftNowTitle` HTML identifier typo.
- Prevented Guided Shift rendering from throwing when an optional DOM node is absent.
- Scoped Guided Shift lookups to its own center first.
- Added null-safe text and HTML rendering helpers.
- Added null-safe handoff form handling.
- Updated the Guided Shift asset cache version to `39.6.1`.

## Root cause

The HTML used `guidedShiftNopwTitle` while the JavaScript expected `guidedShiftNowTitle`. The resulting null reference caused Guided Shift initialization and `guided-shift:updated` listeners to throw.
