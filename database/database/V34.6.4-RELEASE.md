# Blue Current V34.6.4 — Application Readability & Contrast

This release applies a system-wide readability layer to the authenticated application.

## Improvements
- Opaque dark surfaces replace washed-out translucent panels.
- Primary, secondary, and muted text receive higher contrast minimums.
- Inputs, selects, textareas, placeholders, and disabled controls remain readable.
- Panel borders are stronger and nested cards are easier to distinguish.
- The AI decision-support and scenario-comparison views receive explicit contrast corrections.
- Keyboard focus indicators are visible throughout the application.
- `prefers-contrast: more` receives an additional contrast increase.

## Scope
This is a CSS and application-shell update. It does not change business logic, APIs, AppState data, or workflow behavior.
