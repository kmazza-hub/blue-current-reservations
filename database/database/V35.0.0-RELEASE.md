# Blue Current V35.0.0

## Restaurant Performance Engine

V35.0.0 introduces the first commercial operating model for Blue Current: a Restaurant Performance Index (RPI) that connects financial performance, guest experience, operational excellence, and AI effectiveness.

### Added

- Restaurant Performance Index with weighted pillar scores
- Revenue available, captured, and remaining opportunity model
- Financial, guest, operations, and AI effectiveness scores
- Ranked performance drivers
- Highest-impact actions with projected revenue and RPI gain
- Confidence scoring and performance trend history
- AppState persistence and EventBus integration
- Restaurant Performance Command Center
- Approval handoff into the existing recommendation/workflow path

### Governance

The financial values are operational estimates generated from current application signals. They are not accounting records or guaranteed outcomes. Actions requiring approval remain human-governed.
