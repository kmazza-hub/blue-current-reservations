# Blue Current V42.5.0 — Live Ingestion Resilience

## V42.3 Event Contract Registry
Canonical event contracts validate source domain, schema version, and required payload fields before data enters the trusted stream.

## V42.4 Event Recovery & Dead Letter Queue
Rejected live events are retained with failure evidence and can be replayed after the source payload or connector is corrected.

## V42.5 Live Operations Bridge
Accepted events are aggregated into a four-hour operating snapshot covering revenue, seated covers, open kitchen tickets, employees on clock, freshness, and event throughput. The browser publishes this snapshot into shared Blue Current state without recurring timers.

No restaurant action is executed automatically.
