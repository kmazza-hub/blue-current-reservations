# Blue Current V38.5.5 — Authentication Recursion Hotfix

Fixes an infinite authentication session loop where `renderSession()` called `AuthSessionCoordinator.updateSession()`, which emitted `bluecurrent:auth-session-state`, which called `renderSession()` again until the browser exceeded the maximum call stack.

## Changes
- Makes `renderSession()` a pure UI/AppState render operation.
- Keeps coordinator updates at explicit session mutation points only.
- Updates the auth module cache version to `38.5.5`.
- Updates the visible build identifier.
