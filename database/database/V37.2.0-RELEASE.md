# Blue Current V37.2.0 — Focused Asset Startup

This release reduces normal startup from roughly 230 script requests to the core operating shell plus essential intelligence modules.

## Changes

- Secondary modules are represented as deferred script placeholders during focused startup.
- The startup loader loads only essential assets by default.
- `?full=1` loads the complete legacy platform sequentially for diagnostics and deep drill-down.
- Explore Full Platform controls reload into full mode deliberately.
- The automated MotionEngine timeline remains disabled in focused mode.
- A visible recovery banner appears if a required startup asset fails.
- Build metadata is updated to `37.2.0-performance`.

No feature files are deleted. Deferred modules remain available in full mode.
