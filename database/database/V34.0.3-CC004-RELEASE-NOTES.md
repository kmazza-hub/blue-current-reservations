# Blue Current V34.0.3 — CC-004 Restaurant Readiness Breakdown

## Added
- Clickable Restaurant Readiness score breakdown.
- Six weighted operating signals: staffing, reservations, inventory, equipment, labor, and shift handoff.
- Per-signal score, status, explanation, and weighting.
- Strongest and weakest operating-signal summary.
- Dynamic “Best next action” recommendation based on the lowest readiness component.
- Accessible expand/collapse controls and responsive mobile layout.

## Data behavior
Readiness is calculated server-side from the current location snapshot. The financial baseline remains pilot data until POS history is connected.
