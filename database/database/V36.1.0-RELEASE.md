# Blue Current V36.1.0 — Live Shift Timeline 2.0 & Guided Operator Flow

## Business value

V36.1 reduces operator cognitive load during service. It converts the unified command timeline into an acknowledgement queue, a Now/Next/Later operating plan, and an explicit shift-handoff workflow.

## Implemented

- Material-event acknowledgement queue
- Priority and response-window scoring
- Five-minute event snoozing
- Now / Next / Later operating plan
- Service-phase awareness
- Operator-focus score
- Explicit shift handoffs with ownership and completion
- AppState persistence
- EventBus integration
- Progressive drill-down into source modules

No action is executed automatically and all existing approval gates remain intact.
