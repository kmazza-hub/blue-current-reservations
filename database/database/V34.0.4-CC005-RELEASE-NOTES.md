# Blue Current V34.0.4 — CC-005 Operations Feed

Adds a persistent, filterable restaurant activity feed to the Command Center.

## Included
- New server-side operations feed service and API endpoint.
- Feed categories for operations, staffing, guests, inventory, maintenance, and handoffs.
- Automatic feed entries from existing audit history and shift handoffs.
- New persistent events when handoffs are posted or acknowledged.
- Newest-first ordering, relative timestamps, filters, and expanded history.
- Responsive Command Center feed interface.
