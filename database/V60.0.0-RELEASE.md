# BLUE CURRENT V60.0.0 — OPERATOR PRIORITY & DARK-ROOM READABILITY

This wave applies restaurant-floor UX rules to the finished product:

1. Bright, high-contrast primary surfaces for dim restaurants.
2. Every primary section gets a plain-language purpose label.
3. The top operating path is limited to Command, Live, Host Stand, Floor, Reservations, Staff, Kitchen, Service, AI Brain, and Executive.
4. Supporting operational intelligence remains visible but visually secondary.
5. Specialist/configuration/administrative surfaces remain in the product but are collapsed behind a Tools & Configuration control.
6. Existing V48–V59 advanced release/certification surfaces remain separately recoverable through Product Mode.
7. Inputs, placeholders, focus states, labels, and status chips receive stronger contrast.

Nothing is deleted. The information architecture now reflects restaurant priority instead of development chronology.
