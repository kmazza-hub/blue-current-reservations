# Blue Current V100.3.45

## iPad LAN Acceptance Launch

- Allows RFC1918 private IPv4 browser origins only in development mode so a same-Wi-Fi iPad can perform authenticated mutations.
- Keeps production explicit-origin enforcement unchanged; private LAN origins remain rejected in production.
- Adds `npm run pilot:lan`, which discovers the Windows computer's private network addresses, prints the correct Safari URLs, and runs Blue Current until Ctrl+C.
- Advances the protected one-command certification through V100.3.45.
- Does not expose arbitrary public origins, deploy hosting, alter restaurant configuration, or include database files.

Rollback removes the LAN launcher, reverts the development-only private-origin allowance, and restores the prior release identity.
