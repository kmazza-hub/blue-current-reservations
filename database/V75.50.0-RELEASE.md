# V75.50.0 — Blue Current Hospitality OS Application Shell

V75.50 changes the default localhost experience from a long host/reservation-oriented product page into the operating command surface for the full Hospitality OS.

## Default command view

The first authenticated operating view now establishes:
- location and service-period context
- live restaurant status
- what needs attention now
- next-30-minute pressure
- Blue Current Intelligence
- shift profitability
- direct specialist workspace launch

## Application hierarchy

The shell introduces ten primary workspaces:
1. Command
2. Guests
3. Service
4. Team
5. Kitchen
6. Inventory
7. Performance
8. Executive
9. Integrations
10. System

Existing deep product modules are preserved. They are progressively disclosed only when their workspace is opened instead of overwhelming the default view.

## Host Stand

The Host Stand remains intact and is now positioned inside the Guests workspace. It is no longer the identity of the entire application.

## Environment model

`localhost:8787` is the local development environment for the future authenticated application surface (`app.bluecurrentco.com`).

The public `bluecurrentco.com` remains the marketing/story/pilot website.

## Operating UX

- high contrast for dark restaurant environments
- large interaction targets
- mobile bottom workspace rail
- calm command view
- specialist controls hidden until needed
- shell performs no API mutation and creates no second operational source of truth
