# V80.0.0 — Pilot Data Authority & Operational Cutover

V80 closes the V79 integration-readiness sequence with an explicit human-controlled cutover.

Provider authority is never granted merely because an adapter is connected. Cutover requires stable trusted continuity and an admin action.

Initial certified authority is intentionally narrow:
- provider: reservations and sales
- Blue Current: service, kitchen, labor, inventory, guests

Rollback restores local Blue Current authority immediately.

There is no automatic cutover and no automatic re-cutover after rollback.
