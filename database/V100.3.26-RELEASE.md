# V100.3.26 — Authorized District Truth

Prevents built-in illustrative portfolio locations from being presented outside the signed-in user's authorized restaurant boundary.

## Certified improvements

- Filters District Command cards and KPIs through the shared authorized restaurant list.
- Restricts district selection to restaurants that remain visible after authorization filtering.
- Clears and disables the district alert when no authorized portfolio restaurant is available.
- Rebuilds District Command when the shared restaurant authority changes.
- Removes the Executive Morning Brief's built-in fallback portfolio.
- Shows an explicit verified-data unavailable state instead of substituting illustrative locations.
- Clears and disables Morning Brief focus until a verified district location exists.

## Preserved

- Development/demo behavior remains available before an authorization list exists.
- Authorized executives can still rank and review multiple permitted restaurants.
- Existing risk, health, revenue, labor, guest, and alert calculations remain unchanged for visible locations.
- No server route, database record, permission list, or live restaurant state is modified.
