# V88.25.0 — Pilot Location Configuration Certification

V88.25 converts restaurant configuration from "present" into a certifiable pilot gate.

A location cannot be certified until its persisted configuration validates its identity,
service periods, dining areas, table map, operating roles, turn target, integration
assignments, pilot mode, and safety locks.

Certification is tied to the exact configuration update timestamp. Any subsequent
configuration change automatically requires recertification.

Provider write-back and autonomous production changes remain disabled.
