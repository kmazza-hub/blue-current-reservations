# V100.3.3 — Operator Review Evidence Integrity

Makes the V100.3.2 hands-on review protocol safely recordable without changing the live restaurant application.

The interactive recorder creates or resumes one evidence file, walks only unreviewed scenarios, requires observed evidence for every rating, and requires severity plus an operator note for friction or blocked work. Each save is written through a temporary file and renamed into place so an interrupted write does not leave a partial review.

`READY` is refused while scenarios remain unreviewed or any blocked, high, or critical finding remains. An early `HOLD` can preserve a critical stopping point. Once a decision is recorded, scenario evidence is immutable. The recorder produces both structured JSON and a readable Markdown report.

No runtime UI, server route, restaurant state, automatic approval, or automatic workflow change is introduced.
