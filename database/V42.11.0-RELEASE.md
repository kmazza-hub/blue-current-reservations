# Blue Current V42.11.0 — Live Evidence Control

## V42.9 Source Checkpoints
Persists a monotonic checkpoint per live connector whenever a canonical event is accepted. Checkpoints expose sequence, event IDs, schema/adapter provenance, and freshness state so interrupted feeds can be identified without guessing.

## V42.10 Replay Window Control
Provides a bounded event-window API and UI for previewing stored canonical events and republishing them through the realtime hub for recovery/diagnostic workflows. Replay publication does not create duplicate persisted canonical events.

## V42.11 Reasoning Feed Gate
Creates an explicit trust boundary between V42 live ingestion and V41 reasoning. The feed evaluates operating snapshot freshness, configured/live source freshness, delivery rejection/dead-letter state, and exposes `safeToReason` plus blockers. The client publishes this into shared AppState as `liveReasoningFeed` and `liveEvidenceTrusted`.

No restaurant action is executed automatically.
