# BLUE CURRENT V60.50.0 — SHIFT FOCUS & UNIVERSAL USABILITY

Second systematic product-perfection wave.

The operating principle is simple:
WHAT IS HAPPENING? -> WHAT NEEDS ATTENTION? -> WHAT SHOULD I DO?

V60.50 adds:
- Shift Focus as the default restaurant workspace
- supporting intelligence hidden by default but available with Show insights
- specialist/configuration tools retained behind the existing Tools control
- release/certification controls retained behind the existing Advanced control
- a sticky primary-workspace jump bar
- explicit purpose labels for top-level supporting and specialist surfaces
- 46px minimum interactive control height
- 16px operational input text for readability and mobile usability
- inferred accessible names for unlabeled controls
- visual distinction between primary, secondary, and caution actions
- reduced visual emphasis for empty placeholder values
- reduced-motion support

No workflows, APIs, forms, or control surfaces are deleted.
