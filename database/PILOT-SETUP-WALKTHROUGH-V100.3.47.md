# Pilot Setup Walkthrough

1. Start Blue Current and sign in as an administrator.
2. Add `?pilotSetup=1` to the address.
3. Confirm the actual restaurant identity, timezone, dining areas, table map, read-only POS source, your name, and confirmation source.
4. Save only after comparing the values with the restaurant's real floor plan and operational data.
5. Certify the configuration, build the protected workflow binding, and run all isolated scenarios.
6. When all four steps show READY, open the physical walkthrough.

The setup console never enables provider write-back or approves physical evidence automatically.
