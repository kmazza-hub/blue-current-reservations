# V100.2.63 — Kitchen / Service Rush Handoff Certification

Certifies the Kitchen ↔ Service handoff under multiple simultaneous active tables.

The contract verifies that:

- each party has an independent guest + party size + table identity;
- only Ordering parties enter Kitchen;
- Ready outranks aging exceptions;
- duplicate Ready signals collapse to the same party;
- one Food delivered transition clears only that party's Ready state;
- Kitchen never auto-advances Service;
- protected Host/Floor behavior remains untouched.

No runtime application files are modified.
