# BLUE CURRENT V50.5.0 — PRODUCTION OPERATIONS HANDOFF

V50 begins Blue Current's steady-state production operations phase.

V49 answered:

`Can a restaurant move from rollout approval through stabilization safely?`

V50 begins answering:

`Once a restaurant is stable, who owns it in production and under what operating/reliability conditions?`

## V50.01–V50.05 — Production Operations Handoff

This wave deliberately reuses the existing Blue Current reliability/SLO system rather than creating a second observability stack.

A location becomes eligible for production-operations acceptance only after a human `STABLE` declaration from V49 Launch Stabilization.

## Production acceptance gates

Each stabilized restaurant is evaluated against:

1. Human STABLE declaration exists.
2. Existing platform reliability/SLO state is not breached.
3. Restaurant operating readiness is at least 70.
4. Leadership attention is not High/Critical.
5. No urgent predictive intervention is active.

The platform reliability gate comes from the existing `ReliabilityAutomationService`, including:

- SLO status
- reliability score
- breached objectives
- warning objectives
- error-budget remaining

## Human production ownership

Adds:

`POST /api/production-operations-handoff/locations/:locationId/accept`

Acceptance requires:

- authenticated admin permission
- location inside authorized scope
- named production support owner
- named escalation owner

Optional operational ownership fields:

- support hours / coverage
- maintenance window
- handoff note

If one or more production-acceptance gates are open, a documented executive override reason is required.

## Critical separation

Production-operations acceptance is an ownership / governance transition.

It does not change application runtime, infrastructure, connector state, or restaurant configuration.

Each acceptance explicitly records:

- `status: ACCEPTED_INTO_PRODUCTION_OPERATIONS`
- `runtimeMutationPerformed: false`

## Policy

- `stableDeclarationRequired: true`
- `adminAcceptanceRequired: true`
- `supportOwnershipRequired: true`
- `acceptanceDoesNotModifyRuntime: true`
- `automaticAcceptance: false`
- `automaticRemediation: false`
- `autonomousProductionChanges: false`
