# V71.0.1 — Google Fonts CSP Compatibility Hotfix

Fixes the browser CSP violation that blocked the Google Fonts stylesheet used by the Blue Current interface.

Changes only the relevant CSP source allowlists:
- `style-src` adds `https://fonts.googleapis.com`
- `font-src` adds `https://fonts.gstatic.com`

No wildcard source is introduced. Script, connection, frame, object, form, and image policies are unchanged.
