# V100.2.22 Release — Trustworthy Table Lifecycle + Predictive Availability

This release converts the Host Stand floor from ambiguous time labels into explicit operational states and establishes the table-trust contract.

## Operator states

- `OPEN` — confirmed available now.
- `SEATED · Xm` — factual elapsed seating time.
- `OPEN ~Xm` — predicted availability only.
- `CHECK TABLE` — turn target reached; human verification required.
- `CLEANING · Xm` — party has left and table is being reset.
- `RESERVED · time` — held for a future reservation.

## Lifecycle

`OPEN → SEATED → Party left → CLEANING → Mark table open → OPEN`

Blue Current predicts likely availability but a staff member owns the factual transition back to OPEN.

## Seating simplification

Table selection now filters to confirmed-open tables that fit the party size. When none fit, the host sees the next likely openings and keeps the party in the ready queue rather than entering a dead-end floor-selection mode.

## Readability

The active seating instruction, confirmation card, and Cancel actions receive high-contrast treatment tailored to the V100.2.20 unified seating controller.
