# V76.0.0 — Command Intelligence & Live Operating Picture

V76 turns the Hospitality OS Command shell from a visual concept into a read-only operating picture derived from Blue Current's persisted restaurant state.

## Real command data

The Command view now loads:
`GET /api/command/operating-picture`

It derives:
- active covers and tables
- configured-seat occupancy
- waitlist parties and average quoted wait
- active staff
- active kitchen tickets
- food-ready item count
- kitchen target minutes
- upcoming reservation demand
- next-30-minute reservations/covers when timestamps are current
- sales forecast, labor budget, and target labor percent when configured
- low-stock count
- rule-based attention signals

## Truthful financial/data labeling

V75.50 contained illustrative command numbers. V76 removes those hard-coded claims.

Blue Current will not invent:
- actual POS revenue
- actual labor percent
- expected table turns

If actual POS data is not available, the UI labels forecast/target data explicitly.

Historical seed data is also labeled as historical rather than being represented as live telemetry.

## Attention intelligence

The initial attention engine surfaces verified rules for:
- high-priority/held kitchen work
- food ready at expo
- wait above configured threshold
- occupancy above configured threshold
- inventory below 60% of par
- VIP reservation context

It recommends where to look; it does not automatically mutate restaurant operations.

## Safety

The Command shell performs GET-only reads. Specialist workspaces remain the systems that execute operational actions.
