# Blue Current V36.0.0 — Unified Restaurant Command

V36.0.0 converts the expanding intelligence backend into one focused operator experience. Existing centers remain intact and available through progressive disclosure.

## Business value
- One screen answers how the restaurant is performing, where profit is exposed, what needs attention, and what to do next.
- Managers receive action-first guidance; executives receive financial context; technical users receive integration diagnostics.
- The live shift timeline connects operational events, recommendations, approvals, and measured outcomes.

## Implementation
- Unified Command Engine and Center
- Role-aware command views
- AI operator question-and-answer guidance
- Highest-impact approval handoff
- Live shift timeline
- Focused command mode with full-platform drill-down
- AppState and EventBus integration

## Safety
No existing intelligence center is removed. Command mode only hides detailed centers visually. Human approval gates remain mandatory. Financial figures remain modeled operating estimates.
