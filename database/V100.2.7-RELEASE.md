# V100.2.7 — Guest Journey Focus & Visibility Lifecycle

## Repair
Guest Journey Live could retain focus on `#guestJourneyPlay` or `#guestJourneyReset` while a legacy/deep-surface controller later hid the section with `aria-hidden`, triggering a browser accessibility warning.

V100.2.7 explicitly releases focus from controls inside `#guest-journey-live` before Run/Reset transitions continue. The journey event sequence and all operating data behavior are unchanged.

## Boundaries
No authentication, shell visibility, routing, reservation, guest search, server, database, RBAC, or persistence changes.
