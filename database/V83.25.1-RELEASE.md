# V83.25.1 — Light Surface Typography Enforcement Hotfix

Corrects remaining light-on-light typography on Host/Guest and Workforce/Team
surfaces.

The hotfix is intentionally appended as the final CSS authority so older
high-specificity dark-theme rules cannot override light-surface typography.

It covers headings, descriptions, eyebrow labels, KPI cards, panel copy,
form controls, placeholders, status text, and mobile rendering.
