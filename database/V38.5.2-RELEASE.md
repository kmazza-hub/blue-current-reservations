# Blue Current V38.5.2 — Authentication Handoff Hotfix

This hotfix corrects the post-startup signed-out state in focused and feature-pack modes.

## Fixes
- Opens the sign-in overlay whenever startup completes without an authenticated session.
- Prevents the underlying Authentication & Organizations center from appearing to be the active pack.
- Focuses the email field for a direct sign-in path.
- Preserves focused startup, pack loading, and all existing authentication controls.
