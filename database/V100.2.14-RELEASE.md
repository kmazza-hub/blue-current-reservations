# V100.2.14 Release — Host Stand Workspace Simplification

Product rule: **Aim small, miss small.**

This release simplifies the Host Stand surface around one job at a time:

- Floor = dining-room map and table work.
- Reservations = arrivals/reservations only.
- Waitlist = waiting parties only.
- Guests = guest search only.
- Leaving Floor clears transient table selection/detail UI.
- Returning to Floor preserves real restaurant state without resurrecting stale cards.

No server, database, authentication, RBAC, persistence, reservation creation, or V100.2.13 seating-state logic is replaced.
