# V100.2.8 — Host Stand Contrast Hardening

## Scope

Hardens the visual contrast of the Host Stand waitlist and arrivals panel after the operational audit exposed dark-on-dark and light-on-light states.

## Changes

- Bright, readable inactive Waitlist / Arrivals tab labels.
- Dark, readable text on the active light tab.
- Bright guest names and readable secondary details/times.
- High-contrast enabled Seat actions.
- Readable completed/disabled Seated actions without over-dimming the entire row.
- Readable Arrived / Expected status chips.

## Guardrails

No changes to queue switching, per-party seating behavior, reservation lifecycle, authentication, navigation, server APIs, database, RBAC, or persistence.
