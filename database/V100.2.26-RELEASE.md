# V100.2.26 — Dynamic Wait Quote + Functional Reserved Table Tools

Blue Current now gives the host one simple current wait quote derived from queue position and predicted table availability, while keeping detailed timing underneath the surface. No-table guidance is reduced to queue position plus one estimate.

Reserved tables are no longer dead-end detail cards. A host can link a guest, mark a linked expected reservation arrived, seat a linked ready guest, release an unused reservation, or close the tool cleanly.

Design rule: **Aim small, miss small. Show the host the next decision, not every number.**
