# Blue Current V42.38.0 — Enterprise Pilot Cutover

Adds location live cutover control, portfolio live telemetry, and enterprise pilot cutover certification.

## V42.36 Location Live Cutover
Promotes each restaurant through sandbox, pilot, and live stages only when location coverage and trusted evidence satisfy the required controls.

## V42.37 Portfolio Live Telemetry
Combines location coverage, cutover stage, readiness, connector activity, and enterprise trust into a portfolio-wide operating signal.

## V42.38 Enterprise Pilot Cutover Certification
Creates a governed certification gate for a controlled multi-location restaurant pilot. No provider traffic or restaurant operation is changed automatically.
