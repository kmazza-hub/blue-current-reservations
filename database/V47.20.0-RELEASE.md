# BLUE CURRENT V47.20.0 — SERVICE PROFITABILITY INTELLIGENCE

## Scope

V47.16–V47.20 adds a restaurant profitability decision layer built from the operating data Blue Current already has.

The goal is not to manufacture a full P&L.

The goal is to answer:

`What controllable operating constraint is costing the restaurant the most money right now?`

## V47.16 — Modeled Controllable Contribution

Blue Current now calculates a modeled controllable contribution using:

- sales forecast
- modeled food cost
- projected labor
- recorded waste

The result is explicitly labeled:

`Modeled controllable contribution`

It does not claim to represent GAAP net income.

Excluded from the current model:
- rent / occupancy
- utilities
- insurance
- depreciation
- taxes
- financing
- corporate overhead
- unmodeled POS discounts / comps

## V47.17 — Profit Leakage Model

Blue Current converts current operating constraints into modeled leakage dollars.

Current categories include:
- food-cost variance
- labor above target
- kitchen throughput drag
- waitlist conversion leakage
- unavailable seat capacity
- unassigned reservation exposure
- recoverable guest revenue
- revenue target gap

Each constraint includes:
- modeled leakage dollars
- explanation
- next corrective action
- confidence
- supporting operating metrics

## V47.18 — Service Productivity Signals

The profitability model also tracks:
- seated tables
- available tables
- unavailable seats
- delayed kitchen tickets
- delayed covers
- waitlist parties
- long-wait parties
- wait-exposed covers
- unassigned reservation covers

These signals connect service execution to financial opportunity rather than treating operations and profitability as separate dashboards.

## V47.19 — Profitability Bridge

The UI now presents a controllable contribution bridge:

Sales Forecast
→ Food Cost
→ Labor
→ Waste
→ Modeled Controllable Contribution

The bridge is accompanied by a ranked profit-constraint list so a manager can see both:

1. where the modeled contribution stands
2. what constraint should be addressed first

## V47.20 — Shift Profitability Snapshot

Adds:

`POST /api/service-profitability/snapshots`

Managers can capture the current profitability state as a shift snapshot.

The record stores:
- sales forecast
- controllable contribution
- controllable margin
- food-cost position
- labor position
- waste
- productivity signals
- largest current constraint
- methodology / model boundary

Snapshots are persisted in the existing `profitSnapshots` collection, audited, and emitted through realtime events.

## API

### GET
`/api/service-profitability?locationId=<location>`

Returns the live profitability model and ranked constraints.

### POST
`/api/service-profitability/snapshots`

Captures the current profitability state.

Both require authentication. Snapshot writes require write/admin permission.

## Important interpretation

The $6,023 leakage total is not presented as guaranteed incremental profit.

It is a modeled operating exposure across different signals. Some opportunities can overlap.

Blue Current uses this figure to prioritize attention, not as an audited accounting result.
