# BLUE CURRENT V51.45.0 — MANAGEMENT & EXECUTIVE ACCURACY

V51.41–V51.45 hardens management and executive reporting so pilot-critical KPIs cannot look trustworthy merely because a dashboard can display a plausible number.

## Major issue found and corrected

The Executive Command Center still contained deterministic/modelled fallback values for several locations when authoritative restaurant data was missing.

Those fallbacks could create plausible-looking values for:

- revenue
- prior-day revenue/trend
- table counts / occupancy
- guest counts
- ticket counts/timing
- staff counts
- health

V51.45 removes those deterministic KPI fallbacks from the executive surface.

Missing authoritative metrics now remain:

`null / unavailable`

instead of being silently modeled.

The Executive UI was also hardened so unavailable metrics display as:

`—`

rather than being converted to zero.

## Executive data policy

The Executive Command Center now reports:

- `syntheticFallbacks: false`
- `missingAuthoritativeMetricsRemainNull: true`
- `financialMetricsRequireFinancialSource: true`

Every location includes provenance metadata and:

- `syntheticFallbackUsed: false`

## Accuracy certification layer

V51.45 adds source reconciliation for:

- occupancy
- active reservations
- active waitlist
- active staff
- active kitchen tickets
- guest / cover count
- revenue

The certification compares the Executive Command Center value against authoritative source collections.

Possible states:

- MATCH
- DISCREPANCY
- UNVERIFIED
- MISSING_DISPLAY_VALUE

## Authoritative sources

Current operational sources include:

- tables
- reservations
- waitlist
- staff
- kitchenTickets

Revenue requires an actual financial source, such as:

- financialSnapshots
- locationFinancials
- revenueSnapshots

A deterministic or modeled revenue number can never satisfy revenue provenance.

## Portfolio reconciliation

Portfolio occupancy, guest count, and revenue are also reconciled against location source data.

Critical location/portfolio discrepancies or unverified revenue block certification.
