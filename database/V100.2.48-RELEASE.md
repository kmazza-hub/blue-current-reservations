# V100.2.48 — Floor Cell Readability Lock

A surgical readability pass on top of V100.2.47.

- Capacity (`2 TOP`, `4 TOP`, etc.) now lives inside the physical table cell instead of floating above it.
- Table numbers and live states are larger, bolder, and higher contrast.
- `CLEANING`, `CHECK`, `OPEN`, `SEATED`, and reservation times are constrained inside the table marker.
- 2-, 4-, 6-, and 8-top markers are sized for their complete content.
- Busy-state type is white; light-state type uses deep Blue Current ink.
- The organic room layouts and all current reservation, waitlist, seating, and guest-intelligence behavior are preserved.
