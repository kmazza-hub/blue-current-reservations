# V100.3.50 — Hosted Restart Rehearsal

This wave proves the production startup lifecycle against a disposable copy of a human-selected database.

- Starts the real server in production mode with an explicit HTTPS origin and temporary external persistence path.
- Verifies health, performs graceful SIGTERM shutdown, confirms the verified backup pair, restarts, and verifies health again.
- Confirms organization, location, user, and table counts survive unchanged.
- Deletes the disposable rehearsal directory and never mutates the selected source.

No external deployment, DNS change, pilot activation, live database, or automatic rollback is included.
