- Success-gate PASS/OPEN presentation
- Per-location objective and target review
- Pilot exception summary
- Recommendation, confidence, rationale, and next action
- Human-readable text packet for copying into executive communications
- Immutable-style archived review snapshots in `executivePilotReviews`
- Audit event and realtime publication when a packet is archived

## Evidence boundaries
The packet preserves the V48 evidence discipline:
- verified realized value comes only from measured completed-action outcomes
- readiness, operating rhythm, and modeled leakage are observed movement
- observed movement is not automatically attributed to Blue Current
- recommendation is decision support only
- commercial commitment requires a human
- automatic commercial commitment is disabled
