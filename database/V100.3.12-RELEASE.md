# V100.3.12 — Host Lifecycle Certification

- Makes seating through the reserved-table workflow publish the same authoritative event as standard seating.
- Carries table identity, party size, and seated time from reserved-table seating into Service.
- Resynchronizes Host counts and live wait estimates after lifecycle cleanup.

- Walk-in creation and waitlist entry.
- Standard seating eligibility and confirmation.
- Floor zone switching, CHECK, CLEANING, OPEN, and full-screen behavior.
