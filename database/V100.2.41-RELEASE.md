# V100.2.41 — Host Focus Simplification

This release removes two sources of unnecessary host-screen clutter.

## Floor
The fixed `Tonight’s moments` block is removed from the Floor sidebar so it cannot compete for vertical space with the live waitlist.

## Reservation details
`Mark arrived` is removed. `Add to waitlist` is now the single operational handoff from reservation detail into the live Floor seating queue. The handoff still updates the reservation state to Arrived internally, deduplicates the queue entry, and returns the operator to Floor > Waitlist.

Edit and cancel reservation remain available.
