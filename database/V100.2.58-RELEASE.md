# V100.2.58 — Completed Visit Memory / Table Turn Certification

This wave closes the first full Service-to-turn memory loop without redesigning Host/Floor.

- A successful Service completion records a deduplicated completed visit in the existing Guest registry.
- The visit records table, party size, completion time, and that the table entered CLEANING.
- CLEANING → OPEN remains a deliberate human action on the existing Floor lifecycle card.
- When that action occurs, Blue Current certifies the turn as complete and clears stale `bcPartySize` ownership data.
- No Floor renderer/controller logic is replaced by this wave.
