# V100.3.24 — Executive Action Location Integrity

Prevents portfolio-level recommendations and actions from silently falling into Marina when a restaurant identity is missing.

## Certified improvements

- Excludes malformed district cards that do not identify a restaurant.
- Requires an explicit verified restaurant before an executive recommendation can create a manager action.
- Uses the same restaurant for executive action creation and its attached note.
- Carries restaurant identity from rendered recommendations into the Executive Action Center.
- Prevents locationless seed actions and locationless manager-action events from entering the executive ledger.

## Preserved

- Executive views remain portfolio-wide and multi-location.
- Valid district recommendations continue to target their own restaurant, not the currently selected frontline location.
- Existing priority, ownership, completion, review, and navigation behavior remains unchanged.
- No server route, database record, authorization list, or live restaurant state is modified.
