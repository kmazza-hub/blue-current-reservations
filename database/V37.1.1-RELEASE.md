# Blue Current V37.1.1 — Startup Stabilization

This hotfix changes the browser startup model from eager initialization to a safe focused startup.

## Changes

- Safe startup is now the default.
- Only the Unified Command experience and essential operator modules initialize initially.
- Detailed centers remain in the repository but do not initialize during normal startup.
- The automated MotionEngine timeline no longer starts during safe startup.
- Legacy high-cost application modules are deferred.
- Secondary V36/V37 centers are hidden during safe startup.
- `?full=1` enables the full legacy startup for controlled diagnostic use.
- Build metadata is updated to `37.1.1-stable`.

## URLs

Normal safe startup:

`http://localhost:8787/`

Diagnostic full startup:

`http://localhost:8787/?full=1`

Use full startup only for testing until the remaining modules are converted to activation-based loading.
