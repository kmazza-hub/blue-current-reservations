# V100.2.13 Release

## Reservation Arrival & One-Tap Seating Flow

This patch preserves the V100.2.12 dynamic table-selection ownership model while making the host workflow match restaurant intent:

- reservations remain in Arrivals, not Waitlist;
- Expected reservations may hold/reserve a selected table;
- Anthony has an explicit Mark arrived action in Arrivals;
- Arrived reservations can be seated to an available selected table with one tap;
- Arrivals remains visible through Expected → Arrived → Seated · Table X;
- seated-table detail auto-collapse remains intact.

No auth, Command shell, server, database, RBAC, generic waitlist seating, or reservation-creation logic is changed.
