# Blue Current V100.3.33 — Frontline Mutation Response Integrity

This wave prevents the iPad interface from treating a failed operational mutation as a successful save.

- Table updates return `200` only when the table was actually updated; otherwise they return a clear conflict.
- Kitchen ticket updates, item updates, staff updates, and reservation updates now inspect the stored service result before responding.
- Missing kitchen items return `404`; rejected table, ticket, staff, and reservation changes return `409` instead of `200` with an empty result.
- Successful mutation response shapes and existing lifecycle validation remain unchanged.
- No database or restaurant records are included.
