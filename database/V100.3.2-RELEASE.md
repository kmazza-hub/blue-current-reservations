# V100.3.2 — Human Operator Review Protocol

Opens the planned hands-on operator-review phase without declaring an unobserved result.

The protocol covers twelve current V100 workflows across Host, Floor, Service, Kitchen, Staffing, Manager, iPad resume, and rush readability. Every scenario defines one job, its real starting condition, expected lifecycle result, concrete observation points, and the relevant profitability lens.

All ratings, evidence, reviewer identity, restaurant, device, and READY / REVISE / HOLD decision are deliberately blank. This wave adds no runtime UI, dashboard, data store, automatic approval, workflow mutation, or unmeasured value claim.
