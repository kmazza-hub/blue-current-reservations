# Blue Current V100.3.9 — Focused Workspace Stabilization

Evidence-driven stabilization on top of V100.3.8.

## Changes
- Makes focused workspace mounting idempotent so duplicate focus requests cannot overwrite a workspace's original DOM placement.
- Fixes repeat re-entry for Service and Kitchen: open → Back → reopen works without refreshing.
- Removes the duplicate Rush Dock focus path once the canonical workflow wrapper is installed.
- Keeps Kitchen Throughput Coach visible while portaled and refreshes its live surface after mounting.
- Makes Back/Exit deterministic: restore the workspace, activate Guests, select the Floor host view, and return to the Host Stand instead of an arbitrary long-page scroll position.
- Locks the focused Quick Jobs dock to one consistent width, six-column geometry, and button size across Find Guest, Service, Kitchen, and Staff.

## Preserved
No changes to auth, API behavior, persistence, guest search semantics, seating state transitions, Service business logic, Kitchen business logic, staffing truth, or Floor geometry.

## Physical acceptance sequence
1. Service → Back → Service → Back → Service.
2. Kitchen → Back → Kitchen → Back → Kitchen.
3. Staff → Back → Staff.
4. Find Guest → Back → Find Guest.
5. Confirm Back always lands at Host Stand / Floor.
6. Confirm the Quick Jobs dock does not resize between focused workspaces.
