# V89.75.0 — Pilot Runtime Observability & Incident Control

Adds a runtime operating picture for controlled pilot sessions.

Blue Current can record runtime metrics and manage pilot incidents through OPEN,
ACKNOWLEDGED, ESCALATED, and RESOLVED states. Session events, metrics, and incident
lifecycle events are combined into a chronological pilot service timeline.

A CRITICAL incident pauses an ACTIVE pilot session as a guardrail. Observability never
executes restaurant operations, writes to external providers, or makes autonomous
production changes.
