# V100.2.43 Release

This release tightens the Host Stand state model and restores the preferred premium floor composition.

- Reservations is now an expected-arrivals workspace: after `Add to waitlist`, the reservation card is removed.
- Walk-ins, arrived reservations, and seated parties are saved into a deduplicated Guests registry.
- Guests shows recent saved records even before a search term is entered.
- Main Floor, Waterfront, and Private Dining return to more organic room-like spacing while keeping direct collision-safe coordinates.
- No changes to table-fit rules, seating confirmation, room zoning, wait-time logic, or core table lifecycle.
