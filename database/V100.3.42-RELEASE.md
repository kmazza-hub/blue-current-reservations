# Blue Current V100.3.42

## Hosted Pilot Environment Gate

V100.3.42 closes the remaining identity and persistence gaps between local testing and a safely hostable pilot.

### Production gates

- Requires one explicit HTTPS `BLUE_CURRENT_PUBLIC_URL`.
- Requires the public URL to appear exactly in `BLUE_CURRENT_ALLOWED_ORIGINS`.
- Requires an absolute production database path.
- Rejects production database storage inside the deployed application repository.
- Surfaces the public URL through admin deployment-readiness diagnostics.
- Carries these checks into the pilot environment deployment gate.

### Certified behavior

The isolated certification starts Blue Current in production mode as `https://pilot.bluecurrentco.com`, verifies exact-origin CORS, rejects temporary tunnel origins, verifies hardened response headers, confirms external persistent storage and backup creation, restarts the server, and proves the authenticated session survives.

### Boundaries and rollback

This release does not deploy infrastructure, change DNS, modify `bluecurrentco.com`, activate a pilot, or include a database. Rollback reverts the environment-gate service, readiness projection, environment template, and V100.3.42 certification documents.
