# BLUE CURRENT V65.50.0 — RUSH-HOUR SPEED & SERVICE COMPRESSION

Focused real-service speed wave.

Adds Rush Mode for high-pressure restaurant use:
- persistent one-tap dock for Walk-in, Reservation, Find guest, Service, Kitchen, and Staff
- Alt+1 through Alt+6 shortcuts for those same canonical jobs
- Host Stand rush compression: primary actions enlarged, lower-priority feed hidden during Rush Mode
- Service high-risk / critical / food-ready filters emphasized
- Kitchen recommended moves automatically sorted critical-to-low
- Staffing recommendations visually promoted
- existing Quick Jobs and canonical workflow router reused rather than duplicated

Rush Mode is enabled by default and can be turned off from the operator utility bar. No workflow or backend capability is removed.
