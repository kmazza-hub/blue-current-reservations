# V100.3.19 — Location-Scoped Live Service State

Pilot isolation hardening from V100.3.18.

## Certified improvements

- Gives every authorized location its own browser cache for active Service parties.
- Gives every authorized location its own Kitchen ready-state cache.
- Records the current location on every new Host-to-Service handoff.
- Refreshes Service and Kitchen immediately when frontline location authority changes.
- Migrates prior unscoped development cache data into Marina only, preventing it from appearing at a new pilot location.

## Preserved

- The 18-hour live Service window and stale-state pruning remain active.
- Host seating remains the authoritative Service handoff.
- Service completion remains human-controlled and still moves the table to Cleaning.
- Existing backend records and authorization rules are unchanged.
