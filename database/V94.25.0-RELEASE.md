# V94.25.0 — Pilot Device, Network & Onsite Continuity Readiness

V94.25 certifies Blue Current's existing failure-recovery and shift-continuity systems for the
last-mile realities of a restaurant pilot. The gate requires rehearsed API failure, connector failure,
stale-data protection, offline continuity, device-surface failure, and reconnect/reconciliation paths.
Each pilot location also requires a fallback runbook, escalation owner, recovery-time objective,
continued-shift evidence, and no unresolved high/critical findings.

Automatic repair and automatic restaurant-state mutation remain disabled.
