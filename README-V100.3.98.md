# Blue Current V100.3.98 — Holiday Reservation Book

Adds a phone-first, date-specific reservation book for holiday service on top of the certified V100.3.97 responsive interaction baseline. Hosts can record the guest, phone number, party size, reservation time, holiday, seating preference, and notes once; the record persists through the existing authenticated reservation API and continues into the established arrival, waitlist, seating, and floor lifecycle.

The release includes date and holiday filtering, reservation and cover totals, printable backup output, duplicate phone/time protection, and an authenticated **Mark arrived** action. Restaurant-specific capacity, pacing, deposits, and seating windows remain configuration decisions and are not guessed in this release.
