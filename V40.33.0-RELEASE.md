# Blue Current V40.33.0 — Repository Consolidation

## Scope

This maintenance release removes the inactive embedded V32 repository snapshot at:

`Blue-Current-v32.2.3-auth-startup-order-hotfix/`

The directory contained approximately 140 tracked legacy files and duplicated old client, server, database, documentation, and configuration files. It was not referenced by the active V40 application or server startup path.

## Preserved

The cleanup does not remove or change the active runtime files under:

- `client/`
- `client/js/`
- `server/`
- `database/`
- `shared/`
- `scripts/`
- `.git/`

The V40.32 AIP Learning Governance modules and active startup wiring are preserved.

## Application

Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\maintenance\remove-v32-snapshot.ps1
```

Then review and commit the deletion:

```powershell
git status
git add -A
git commit -m "V40.33 repository consolidation"
git push
```
